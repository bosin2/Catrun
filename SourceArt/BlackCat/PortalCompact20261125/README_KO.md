# 짧은 BlackCat 포탈 동작 수정본

이전 모션의 순서를 유지하면서 팔다리 길이를 약 30% 줄였습니다. 얼굴 크기는 유지하고 머리를 몸 위에 가깝게 배치했습니다. 몸통 폭은 8%, 두께는 6% 늘려 짧고 통통한 비율로 맞췄습니다. 기본 모델의 rest pose와 실제 메시도 새 비율입니다.

`Previews/Comparison.png`는 같은 카메라·배율의 이전/수정 비교입니다. `Previews/CompactPortal_30fps.mp4`는 약 9.77초, 30fps Blender 연속 미리보기입니다.

접촉은 앞발을 잠깐 모았다가 빠르게 찍는 박자로 바꿨습니다. 점프는 팔을 길게 늘리는 대신 압축 후 상체를 위로 기울이고 몸 전체가 더 빠르게 솟도록 바꿨습니다. 이전의 걷기 → 앉기 → 귀·고개 갸웃 → 포탈 접촉 → 엉덩이 두 번 → 압축 → 도약 순서는 유지합니다.

## 파일

- `SK_BlackCat_CompactPortal.blend`: 수정 메시와 개별 편집 가능한 네이티브 액션.
- `SC_BlackCat_CompactPortal_Review.blend`: 1–293프레임 전체 미리보기 씬.
- `FBX/SK_BlackCat_CompactPortal.fbx`: 새 스켈레탈 메시.
- `FBX/AN_CompactPortal_*.fbx`: 앉아서 접촉, 준비, 이륙, 공중, 걷기의 개별 애니메이션.
- `handoff.json`: 모든 절대경로·프레임·좌표·검사·임포트 계약.

몸통·다리는 568삼각형이며 이전 632개보다 적습니다. 얼굴·눈·귀·꼬리·장신구는 8,256삼각형을 유지해 전체 8,824삼각형입니다. 108본(기존 이름 78개 + 표면 보조본 30개)을 사용하고, 짧은 비율에 맞춰 바인드 자세를 수정했습니다. Python 없이 저장된 액션으로 재생됩니다.

## 확인한 내용

- 297개 제작 프레임에서 몸통·네 다리 각각 자체교차 및 퇴화면 0, 바닥 관통 0.
- 뒤통수의 남은 몸통 웨이트가 만들던 돌출을 정리했습니다. 얼굴 형태와 면 수는 바꾸지 않았습니다.
- 짧은 rest pose로 다시 바인드할 때 꼬리 혼합 웨이트가 변형되지 않도록 처리하고, 전후 실제 메시 정점 차이를 검사했습니다.
- 앞발의 실제 포탈 접촉, 준비 중 앞발 고정, 네 클립 연결, 저장 후 재열기, FBX 재가져오기를 확인했습니다.
- 단색 재질용 UV 중첩과 원본의 숨은 눈꺼풀 내부 면, 방울 내부의 분리된 추는 유지합니다.

검사 범위는 제작된 동작입니다. 모든 임의의 포즈나 모든 부품 사이 교차를 보장하는 의미는 아닙니다. 정상 속도 영상은 렌더했고 시각 검토는 주요 자세와 연속 프레임을 기준으로 했습니다.

## UE 적용

기존 UE 모델·공유 스켈레톤·맵·시퀀스는 수정하지 않았습니다. **새 모델과 새 스켈레톤을 별도 에셋으로 가져와야 하며, 기존 스켈레톤에 애니메이션만 덮어쓰면 안 됩니다.** 바인드가 변경되어 이전 두 수정본과도 별도입니다. 권장 임포트 스케일은 기존 원본의 내보내기 계약을 따른 100이며 새 모델의 실제 UE 크기와 런타임 재생은 아직 확인하지 않았습니다.

제자리 클립에는 월드 이동이 없습니다. 영상의 전방·상방 궤적은 미리보기 씬에서만 적용했습니다. 정확한 박자와 접촉 위치는 `handoff.json`을 참고하면 됩니다.
