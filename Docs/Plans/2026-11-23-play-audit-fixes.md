# 2026-11-23 플레이 감사 결함 수정

기준 커밋: e4c730415557656f84fc22f682df676c1829558f.
요구사항: Docs/Reviews/PlayAudit_2026-11-23.md에서 확인한 결함을 수정한다. 저장 해금 보존과 철창 너머 포획을 우선한다. 동상 되돌리기 버튼은 복구하지 않는다.

## 순서와 담당 범위

1. Flow 담당: 저장 읽기 실패를 정상 빈 저장과 구분하고 재시도/쓰기 보호. 새 게임은 최고 해금을 보존. 미러 맵의 챕터 식별, 일시정지, 재시작, 출구 완료를 통일. 포획 중 수동 재시작은 요청 성공 후 메뉴를 닫고, 실패를 조용히 버리지 않게 한다.
2. AI/퍼즐 담당: 시야뿐 아니라 실제 몸체가 통과할 수 있는 짧은 구간인지 확인한 뒤 포획. 동상은 발판 도착을 유지하면서 회수 불가능한 벽/코너로 밀리지 않도록 공통 접근 여유 검사. 공개 방울 호출도 숨기 상태를 존중.
3. UI/입력 담당: 연출 중 숨겨진 저장 실패 안내는 표시 가능한 시간으로 수명을 계산. 재지정 키가 엔진 Alt+Enter와 충돌하지 않게 한다.
4. 메인 담당: Stage1 시작점 문을 기존 가림 처리 방식에 연결하고 원래 재질 외형/물리/배치를 보존. 정식/미러 맵에 적용.
5. 메인 통합: 네이티브 빌드, 관련 자동화, 격리 저장 장애 재현, Gate11/정상 포획, 동상 회수와 발판, 설정 재시작, 시작점 화면, 미러 흐름을 검증. 별도 리뷰 에이전트가 코드/규칙/증거를 확인.

## 제약

- 공용 C++ 코드를 우선하며 행위자 이름이나 특정 동상 좌표 예외로 문제를 우회하지 않는다.
- 소리 전파/기본 감지, 기존 시네마틱/미니맵, 튜토리얼 연출, 제거한 동상 되돌리기 버튼을 유지한다.
- 기존 사용자 저장/설정과 무관한 작업은 보존한다. 실패 주입은 격리 UserDir에서만 수행한다.
- 언리얼/MCP/빌드/바이너리 에셋 저장은 메인 에이전트만 수행한다. 작업자는 지정 소스와 테스트만 수정한다.
- 화면 자동 조작 없이 MCP와 별도 오프스크린 실행을 사용한다. 새로운 푸시는 이번 요청에 포함되지 않는다.
- 이전 감사의 실제 실패 기록을 RED 근거로 삼고 새 회귀 검사를 보강한다. 수정 후 동일 조건으로 GREEN을 확인한다. 새로운 순수 규칙은 실패 검사를 먼저 작성한다.
- 현재 main의 실사용 체크아웃에서 작업한다. 사용자가 이 프로젝트를 계속 수정하도록 명시했으며 UE 에셋/설정 경로를 분리해 중복 에디터를 만들지 않는다.

## 합격 조건

- 일시 읽기 실패 뒤 기존 Stage2 해금이 보존되고 복구 후 이어하기가 정상 활성화된다. 읽을 수 없는 기존 슬롯은 덮어쓰지 않는다.
- 닫힌 Gate11 반대편 포획은 거부하고 장애물 없는 정당한 포획은 유지한다.
- C를 잘못 밀어도 고양이가 회수할 공간을 유지한다. A/B/C 발판 정답과 문 열기는 작동한다.
- 수동 재시작은 포획 소유권/입력/카메라를 남기지 않고 명시적 재시작 정책을 따른다.
- 도착 연출 이후 실패 안내를 읽을 수 있고 SoundTest 맵도 설정 일시정지/재시작/완료가 작동한다.
- Stage1 기본 시작점 고양이가 문에 완전히 가려지지 않는다. 원본 문 재질/메시는 보존한다.
