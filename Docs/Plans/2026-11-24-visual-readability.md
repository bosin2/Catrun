# Stage2 책장 가림과 전환 연출 가독성 수정

기준: 로컬 main `5826054`. 사용자는 언리얼을 켜두었으며 플레이·편집하지 않는다고 확인했다. 원래 맵은 MainMenu, MCP 연결과 dirty 0을 확인했다. 기존 미게시 오디오·도구·감사 변경은 보존한다.

## 목표

- Stage2와 SoundTest_Stage2 책장이 고양이를 가릴 때 벽과 같은 판정·연속 투명도 전환을 적용한다. 책장 외형, 배치, 충돌, 소리 차단은 유지한다.
- Stage1 포털 출발 및 Stage2 도착 연출에서 흰색으로 날아가는 조명을 조정한다. 포털의 밝은 푸른색과 고양이의 털·얼굴 구분을 함께 유지한다.
- 고양이 화면 위치·크기의 급변, 짧은 반대축 컷, 도착 마지막의 과도한 회전·확대를 줄인다. 문 닫힘/뒤돌아보기, 얼굴 보행, 포털 투샷과 점프, 도착 착지, 고양이 시점 동상→발판→철창, 플레이 시점 복귀라는 기존 흐름을 보존한다.
- 저장, AI, 퍼즐, 전환 승인/종료, 제목·입력 복구 정책은 바꾸지 않는다.

## 확인한 원인과 검증할 항목

- 라이브 책장 재질은 masked+dither, 벽은 translucent이며 두 재질 모두 MF_WallOcclusion의 가림 값으로 1→0.12를 보간한다. 테스트맵에는 원본 불투명 책장이 남아 있다. 가림 판정 자체의 책장 끝 범위와 반투명 내부 정렬은 실제 화면에서 비교한다.
- 실제 출발 시퀀스는 39→57프레임에 0.6초짜리 반대축 컷을 사용한다. 도착 마지막은 286→336프레임 동안 큰 회전과 OrthoWidth 81→1170을 동시에 수행한다.
- 도착 레벨은 manual exposure, physical exposure off, bias 0, bloom 0.18이다. 연출 카메라 일부는 다른 bloom을 덮어쓴다. 출발과 도착의 포털 및 보조 광원 단위·강도를 실제 저장값/렌더로 비교한다.

## 작업 분담과 순서

1. 메인: 라이브 연결, 원본 백업, 화면/속성 기준 자료 수집. 완료.
2. 책장 담당: 공통 벽 가림 함수·설정과 같은 연속 투명도 재질 및 두 맵 적용 스크립트. 원형·충돌 보존 검사 포함.
3. 연출 담당: 출발/도착 카메라 곡선·구도·광원 조정, 다시 실행해도 동일한 author 도구 유지.
4. 검증 담당: 소규모 실제 PIE 화면/카메라 기록 도구. 메인만 에디터를 조작하여 동시 저장·맵 로드 충돌 방지.
5. 메인: 변경 전후 렌더 비교, 필요한 값 보정, 실제 전환 끝의 카메라·입력·제목 복귀 검사, 새 프로세스/재로드 확인.
6. 별도 리뷰: 요구사항 및 실제 증거 검토. 결과·한계를 인계 문서에 기록한다. 이번 요청은 로컬 수정이며 게시하지 않는다.

## 수용 기준

- 책장 중앙/끝/가림 해제 위치를 비교하고 고양이가 가려지는 동안에도 읽을 수 있어야 한다. 두 맵의 연결과 원래 충돌/소리 태그가 같아야 한다.
- 실제 카메라와 후처리를 적용한 출발·도착 화면에서 얼굴과 검은 털이 흰색으로 뭉개지지 않아야 한다. 색·조명 변화는 컷별로 일관되어야 한다.
- 의도한 컷 전환과 컷 내부 이동을 구분해서 기록한다. 컷 내부의 시점 튐과 마지막의 급격한 회전/확대를 제거하고 최종 플레이 카메라에 연결한다.
- 생성·저장 대상 외 파일을 보존한다. 화면 캡처는 필요한 대표 장면과 문제 경계에 한정한다.
