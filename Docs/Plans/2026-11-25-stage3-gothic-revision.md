# Stage3 고딕 군사 경비시설 전면 시각 수정

권한: 2026-11-25 사용자 본문과 첨부 `붙여넣은 텍스트.txt`.
GitHub 푸시 금지 유지. 기존 ColorCorrection 작업도 커밋하지 않은 상태다.

## 고정 조건

- 방 외곽·연결·이동 동선·퍼즐 순서·필수 목표 좌표 및 게임 로직 보존.
- Stage1/2 및 공용 원본은 수정하지 않는다.
- 기존 고양이/적의 실루엣과 애니메이션 보존.
- 시각 수정은 Stage3 전용 새 폴더와 Stage3 레벨에서 수행한다.
- 제작 중인 Blender 원본을 쓰거나 덮어쓰지 않는다. 완성된 전달 파일의 해시를 기록한다.

## 구현 범위

1. 신규 중량추·도킹·연결·잠금쇠 24종의 최종 납품 QA 확인 및 별도 폴더 임포트.
2. 기존 동상·발판의 동일 좌표/기능을 새 중량추·도킹 시각으로 대체.
3. 벽부 다발 기둥, 받침과 상단 몰딩으로 모든 방의 입체감 보강.
4. 전시대는 경사 석재 받침과 혼합 무기로 교체하고, 창고의 일곱 장애물은 역할/통행 유지.
5. 로비·하단 홀의 군수 가구·군기, 성문 홀의 장식 바닥과 중앙축을 구성.
6. 실제 벽등·촛대와 연동한 3800~4200K 국소광, 약한 중립 환경광, 수동 노출.
7. 기존 10종 목표색 유지 + 사슬/도르래 금속 목표 sRGB 72/71/74.
8. 각 구역 실제 플레이 카메라 Lit/BaseColor/DetailLighting, 적/고양이 가독성,
   통행·퍼즐 회귀검사와 원본/게임플레이 계약 비교.
