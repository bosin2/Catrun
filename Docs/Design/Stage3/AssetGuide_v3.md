### 현재 진행 중인 제작 수정 범위

- 벽 200/100/50cm 모듈, 30cm 두께, 300cm 높이 등 기존 기술 계약은 유지한다. 50cm 단위의 외곽 차이를 조립으로 처리하되 벽 공유/코너/개구부 차감은 실제 조립 기준에 맞춘다. 가로/세로가 다른 방을 맞추려고 완성 메시를 비균일 스케일하지 않는다.
- 바닥 200×200cm 기본 모듈은 유지한다. 100cm 및 50cm 길이/폭의 마감 조각(필요 시 25/30cm 등 실제 잔여 폭에 맞춘 절단 모듈)을 조립 가능한 설계로 추가한다. 반복 타일의 크기를 늘리거나 줄이지 말고 팔각석 패턴 및 UV 밀도를 유지한다. 잘린 부분은 벽가 마감 또는 테두리로 처리한다. 5cm 두께/상면 정렬/피벗 계약을 공유한다. 모든 가능한 크기의 메시를 지금 양산하지 않는다.
- 6×11m 전시방의 긴 전시대는 세로 방향 배치에 맞는 분할형 모듈로 제작한다. 기존 E01 250×100×110cm는 한 모듈의 후보이며 전시대 전체 길이가 아니다. 방 외곽을 가득 채우는 단일 가구로 만들지 않는다. S1→P1의 유효 폭/방향 전환 공간 검증 전 모듈 수 확정 금지.
- 9×7m 창고에 장애물 7개를 넣는 전제다. E03/E05/E06/E07의 외형과 다양성을 유지하되 150~175cm 통행 폭 및 ㄱ자 내부벽·출입구 공간에 맞게 폭/깊이를 조정할 수 있도록 설계한다. 전시대·장비장 등을 과대 제작하지 않는다. 현재 제안한 외접 규격은 배치 적합성 검증 전 후보이며, 7개 모두 들어간다는 보장은 없다. 필요하면 외형을 유지한 컴팩트 변형을 제안하고 승인받는다. 100cm 높이 시야 차폐 형상은 보존한다.
- 긴 캣홀은 별도 개구부 H2/H3(60×65cm) 두 개를 잇는 7×1.5m 구간이지 하나의 7m 길이 개구부가 아니다. 양쪽 30cm 벽이 모두 외곽 안에 있다면 내부 폭은 90cm(조건부 계산)다. 통로 내부 돌출 장식, 기둥, 등기구, 가구 금지. 실제 공유벽 구조 확인 전 150cm 유효 통로라고 보고하지 않는다.
- 성문 홀 15×11m 기준으로 장식축·문 앞 확대 패턴·기둥 받침과 카펫의 맞물림을 검토한다. 성문 600×800cm 개구 및 약 1000cm 프레임 높이, 6개 다발형 기둥, 250cm 장식축은 기존 규모 후보 유지. 15×11m는 홀 바닥 외곽이지 문의 높이가 아니다. 중앙 카펫은 원본의 기능/배치 보존 대상이므로 장식 바닥으로 자동 대체하거나 삭제하지 않는다. 카펫 디자인 및 실제 소리 감쇠 설정은 별도 검토; 제작 시 러너 모듈을 확장 가능한 형태로 준비한다.
- 하단 7×8m 홀과 중앙 12.5×3m 복도는 분리된 공간이다. 조명/소품은 두 공간을 구분할 수 있는 반복 모듈로 제작한다. 창문·추가 광원·엔진 배치는 아직 확정하지 않는다.
- 30cm 벽이 양쪽 외곽에 모두 포함된 조건에서 6m 방의 유효 폭은 5.4m, 9×7m 창고는 8.4×6.4m, 3m 복도는 2.4m, 15×11m 홀은 14.4×10.4m가 된다. 실제 공유벽/내부벽/몰딩/가구 및 충돌에 따라 더 달라질 수 있으므로 위 계산은 여유 검토용으로만 사용한다.
- 이번 변경은 **맵 조립용 규격 및 에셋 치수 보정**이다. 기존 v2의 조형, 재질, 캐릭터 변형, 기계 부품, 원본 보존/FBX 검수 계약, Blender 작업 범위는 그대로 유지한다. 이미 제작한 에셋은 우선 재사용 가능성을 검사하고, 실제로 영향을 받는 부분만 수정한다. 엔진 작업과 레벨 제작은 시작하지 않는다.

### 4.1 표 읽는 방법

치수는 별도 표기 없으면 X×Y×Z cm **신규 제작안**이며 기존 조립 계약을 먼저 확인한다. 벽 및 벽부착형은 로컬 길이 X, 두께 Y, 위 +Z를 기본으로 검토한다. 신규 자유 배치형은 +Z 위와 정면 −Y를 기본 후보로 하되, 원본에서 물려받는 에셋은 기존 정면·피벗·조립 기준이 우선이다. 표의 이름은 Stage3 전용 제안명이다. 파일에 같은 이름이 이미 있으면 사용자 확인 없이 덮어쓰지 않는다. 정적 조립품은 실제 움직이는 부분만 독립 오브젝트/FBX로 분리한다. 표에서 여러 이름을 나열한 행은 복수 메시로 계산한다.

- 남청 포인트만 무채색 흑철/먹회색으로 변경, 은회색 본체의 충분한 명도와 탁한 황동선 유지. 갑옷 전체를 검게 만드는 작업 금지. 가슴의 작은 별형 문양은 단순 창끝/세로 마름모형으로 변경하는 작업안. 눈 슬릿/투구 면 또는 견갑에 극소량의 형태 조정은 허용하되 반드시 기존 메시와 리그 우선. 신규 무기·망토·뿔·스파이크 금지.
- 실제 최신 Stage2 .blend 파일 확인 후 복사본으로 작업. 원본 재질 슬롯(Steel/Joint/Brass 등의 실제 슬롯)을 먼저 확인. 텍스처/재질만으로 요구 충족 시 신규 SK 내보내지 않고 필요한 텍스처와 `.blend` 변형 사본만 납품. 메시 변경 시 기존 62본과 bind pose, 본 이름·부모·스킨웨이트·root·hand_l/r·pelvis를 보존. 저장 포즈와 레퍼런스 바운드를 혼동해 리그 스케일 수정 금지.
- Blender에서 기존 액션(Idle/Walk/Run/Turn/DoorOpen/Pickup 등 실제 존재하는 것)을 불러 관절 간섭 및 손 위치 확인. 현재 제공한 최신 Stage2 시각 참조가 실제로 어느 파일인지 보고한다. 실제 UE AnimBP/문 동작은 미검증.

**G02 촛불 — `MI/T_S3_Candle_Wax` 계열 또는 `Candle_Stage3_Material.blend` 변형 사본**

- 최신 Stage2의 밝고 약간 보랏빛으로 보이는 밀랍을 중성에 가까운 창백한 회백색으로 미세 조정. 순백/새까만 밀랍/짙은 적색/청색 마법광을 피한다. 색 차이는 실제 BaseColor와 재질을 확인한 뒤 결정(스크린샷 색 추출을 실측으로 간주 금지). 눈과 불꽃의 색은 원칙적으로 유지.
- 메시·UV·웨이트·리그를 수정하거나 신규 Skeletal FBX를 생산할 이유 없음. 기존 밀랍 재질만 복제/수정하고 텍스처 및 `.blend`를 납품. 원본의 7개 슬롯과 eye_l/r, Idle/DetectCatReact, 루트/부유 기준 손대지 않음. Unreal용 MI는 엔진 단계이므로 지금 생성하지 않는다.

**G03 고양이 — `AN_S3_Cat_PullRing` (별도 후속 Blender 작업)**

고양이 외형과 기존 리그·액션 보존. 고리 높이·핀 이동량·입 접점을 D04~D07 조립에서 확정한 뒤 해당 원본을 읽고 상호작용 애니메이션만 별도 제작한다. 접근 → 고리를 입으로 물기 → 짧게 뒤로 당기기 → 고리가 풀리고 놓기 → 움찔한 뒤 기존 자세 복귀. 1.5~2초는 후보이며 실제 애니메이션과 고리 궤적 정합 후 조정한다. 새 자유 점프/전투/등반 추가 금지. 애니메이션 납품은 신규 Action 및 필요한 FBX, 기존 캐릭터 FBX 전량 덮어쓰기 금지. 엔진 상호작용, Root Motion 선택, 고리 부착/해제 이벤트와 타이밍은 이후 구현 단계에서 검증한다. 본 작업은 캐릭터 정적 외형 제작 완료 후 착수한다.

## 6. Blender 공통 기술·납품 지침

사용자가 제공한 공통 지시문의 핵심을 Stage3에도 그대로 적용한다.

1. **작업 전 확인:** 정확한 원본 파일, 오브젝트·재질·UV·텍스처 연결·단위·축·원점·부품·리그를 확인한다. 모델링 모양과 실제 기능 계약이 충돌하면 임의 수정하지 말고 차이를 보고한다. 원본 인벤토리의 파일명이 같은 것만으로 최신 버전이라 단정하지 않는다.
2. **모델링:** 큰 실루엣 우선. 평면인 바닥은 과도하게 돌출시키지 않고 타일 간 연결·벽 모듈 접합·기둥 상하 조립·가동부 간섭을 검사한다. 불필요한 고폴리·소형 부재 난립 금지. 신규 Static Mesh는 Rotation0/Scale1 목표, 기존 리그에 일괄 Apply Transform 금지. UE 배율 중복 적용 금지.
3. **피벗/축:** 원본 경첩, 모듈 모서리, 공통 발판 높이, 벽 부착점, 조립 기준과 본 위치 우선. 모든 물건에 바닥 중앙 피벗을 강제하지 않는다. 내보내기 축과 FBX 설정은 검증된 기존 파이프라인을 재사용하고, 결과에 기록한다.
4. **재질/텍스처:** BaseColor sRGB, Normal_DX/ORM/마스크 Non-Color. ORM R=AO/G=Roughness/B=Metallic, DX 노멀 G 변환은 Blender 표시용과 UE용 원본 구분. 조명/그림자/Bloom을 BaseColor에 굽지 않는다. 금속과 천에 그린 색을 구분. 실제 황동은 물리적으로 금속, 석재·천은 비금속. 필요한 발광 부위만 분리 마스크, 기본값 0인 원본 유지. 원본 노드 입력값만으로 실제 출력값을 판단하지 않는다.
5. **UV/LOD/예산:** UV0 필수, 건축의 UV1_Lightmap 여부는 기존 파이프라인과 확인. 텍스처 해상도/밀도/슬롯/LOD는 용도·배치 빈도·900cm 카메라 스케일을 바탕으로 합리적으로 제안하고 기록한다. 고해상도 원본을 무조건 복제하거나 숫자만 줄이려고 품질을 저하하지 않는다. 반복 가능한 공통 재질과 아틀라스 우선, 개별 파일 상대 경로와 패킹 확인.
6. **충돌:** 필요할 때만 단순 UCX_정확한MeshName_00 등의 규칙. 캣홀·문틀·철창 하강·경첩 회전 공간·동상 접촉면·판 이동공간을 막지 않는다. 장식 부착물은 별도 충돌이 꼭 필요한지 검토. 100cm 높이에서 막힌 차폐 후보 형상과 실제 표시형을 구분. 복잡 충돌 사용을 임의로 확정하지 않는다.
7. **내보내기:** 에셋별 `.blend`, 필요한 `.fbx`, `Textures/`, 작업 결과. 고정·가동 부품별 피벗과 조립점을 명시한다. 프리뷰 Plane/Cube/조명/카메라가 섞이지 않게 실제 납품 대상만 선택. 별도 임시 장면에서 FBX 재임포트해 치수·축·원점·Scale·조립·UV·부품·텍스처 연결·필요한 리그/액션 검사를 수행한다. 테스트용 임시 장면은 납품 파일에 남기지 않는다.
8. **엄격한 범위 제한:** 레벨 생성, 맵 변경, 인게임 세팅, 코드/BP, UE 임포트, MI 생성, AI/소리/시야/타이머 기능 구현은 하지 않는다. 기존 원본 저장/삭제/덮어쓰기 금지. 에셋 제작용 Blender 파일에 미리보기 이미지·렌더·영상·HTML·카메라·Blender Light 오브젝트·전시용 바닥·전시 씬을 만들지 않는다. 게임용 등기구 메시(F04~F08)는 제작 대상이며 이 제한과 혼동하지 않는다. 이 채팅에서 별도 제공하는 컨셉 이미지는 참고 자료일 뿐 Codex가 제작할 추가 산출물이 아니다.
9. **검증 구분:** Blender 재임포트에서 확인한 결과만 완료로 표시. UE의 실제 임포트/충돌 TraceFlag/Visibility/소리 경로/가림(MPC_CatOcclusion)/AnimBP/문 작동/프레임 성능은 테스트하지 않았으면 미확인이라고 적는다. FBX가 Blender 노드를 그대로 UE에 가져간다고 가정하지 않는다.

지금은 Unreal 인게임 작업을 하지 않는다. 이번 작업은 Blender 에셋 제작과 납품이다. Stage1/2 원본과 기존 프로젝트를 수정하지 마라.
