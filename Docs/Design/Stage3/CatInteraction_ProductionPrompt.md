# 고양이 고리 당기기 제작 및 자체검증 프롬프트

## 제작 지시

현재 게임이 사용하는 `BlackCat/Final/SK_BlackCat_Final.blend`를 읽고 별도 작업 파일에서 `AN_BlackCat_ReleaseRing`을 제작한다. 기존 메시, 얼굴, 눈, 비율, 크기, 재질, 78본 계층·이름·Rest Pose·웨이트를 변경하지 않는다. 원본 파일과 기존 11개 애니메이션을 덮어쓰지 않는다. 게임의 Mesh Scale 2와 Capsule 중심 높이 약 26cm, Mesh 상대 Z -24cm를 기준으로 한다.

30fps, 약 2.4초의 단일 동작. Idle에서 고리를 살피고, 목과 머리를 부드럽게 낮춰 고리 아래쪽에 입을 맞춘다. 짧은 접촉 후 몸의 무게와 목의 작은 후퇴로 당기는 동작을 보여 주고, 고리를 놓고 Idle로 돌아온다. 귀와 꼬리는 작게 후행한다. 귀여운 자연스러운 카툰 타이밍을 사용하되 얼굴 찌그러짐, 과도한 목 늘어남, 리그 추가, 입 모양 재설계는 하지 않는다. 턱 본이 없는 기존 리그의 한계를 지키며 닫힌 입의 접촉과 머리 동작으로 표현한다.

Root 이동·회전은 고정한다. 네 발은 접지하고 미끄러지지 않아야 한다. 시작과 끝은 기존 Idle 첫 포즈와 일치시킨다. 입 접촉점의 전 프레임 좌표를 함께 납품하고, Unreal에서 같은 시간의 고리와 맞춘다. 장치 판정과 소리는 실제 당김 시점에 한 번만 발생한다. 재생 중 중복 상호작용과 방울·바구니 동작을 차단하고, 완료·중단·잡힘·맵 이동 시 동작 소유권을 정리한다.

## 접촉 규격 수정 근거

납품 조립 원안의 고리는 Y -10cm, 아래쪽 접촉 Z 21cm이고, 장치 받침은 Y -30~30cm, Z 0~12cm다. 고양이의 일반 지상 자세로 가까이 접근하면 받침과 충돌하거나 받침 위에서 입 높이가 어긋난다. 원본 메시를 바꾸지 않고 엔진 조립에서 고리를 받침 앞으로 연장하고 연결 체인 수·각도를 맞춘다. 실제 캡슐 스윕, 발 지지면, 입-고리 거리로 최종 위치를 정한다. 이 문제는 수치상 예상이며 엔진 검증 결과를 최종 보고서에 별도로 기록한다.

## 자체검증 지시

1. 제작 전후 메시 좌표·폴리곤·UV·재질 슬롯·웨이트와 Rest Pose 해시가 같아야 한다.
2. 모든 프레임에서 유한 변환, 양의 동일 본 스케일, 고정 Root, 발 접지·미끄럼, 입 접촉 궤적, 몸체/목의 자연스러운 연결을 검사한다.
3. 시작·종료와 기존 Idle의 메시 및 본 포즈 차이를 수치로 비교한다.
4. 정면·측면·사선의 전체 동작을 실제 Blender 결과로 검토한다. 일부 프레임이나 파일 존재만으로 합격시키지 않는다.
5. FBX는 단일 Take, 기존 스켈레톤에 애니메이션만 임포트한다. 새 프로세스에서 프레임 수·시간·본 계층과 변환을 재검사한다.
6. Unreal 실제 재생에서 입과 고리 접촉, 당김과 핀·볼트 타이밍, 중복 입력, 조기 중단, 잡힘, 일시정지, 종료 후 이동 및 AnimBP 복귀를 검사한다.
7. 결함이 있으면 수정 후 해당 검사를 반복한다. 자동 검사·시각 검사·미검증 범위를 구분하며, 전체 오류가 없다는 보증으로 보고하지 않는다.
