# Stage3 통합 기준 — 2026-11-25

기준 자료는 사용자가 전달한 v3 에셋 가이드(`AssetGuide_v3.md`), 최종 납품 매니페스트(`DeliveryManifest_20261125.json`), 기존 채팅의 맵 검토 기록이다. 최종 맵은 `/Game/Maps/Stage3`, 에셋은 `/Game/Environment/Stage3/FinalGuard`에 있다.

## 확정 규격

외곽 치수(cm): 입구 300×200, 로비 1100×600, 하부 홀 700×800, 전시실 600×1100, 창고 900×700, 중앙 복도 1250×300, 캣 우회로 700×150, 통제실 1000×600 및 좌하부 부속 공간 550×150, 상부 복도 300×800, 대문 홀 1500×1100. 벽 두께 30, 높이 300. 바닥 상면 Z=0. 상부 복도 D2에서 대문 홀까지 600.

캣홀 60×65, 동상 120×120×150, 발판 외곽 150/내부 130, D1/D2 유효 개구 140×240 및 하강량 280 이상. 대문 전체 800×100×1000, 개구 600×800. 대기둥 6개는 높이 900의 분할 에셋으로 조립했다. 창고 소품은 장비장 2·방패 2·갑옷 부품 2·보급 상자 1의 7개다.

고정 갑옷 2기와 순찰 갑옷 4기, 고정 촛불 2기와 순찰 촛불 3기를 배치한다. 기존 Stage2 캐릭터 스켈레톤·애니메이션을 재사용하고 Stage3 납품의 색상 변형을 적용한다. 우회로 H3→H2는 중앙 복도로 돌아오며 통제실에 직접 연결되지 않는다.

S1/P1은 D1을 연다. P2에 동상이 놓이고 E1·E2·E3를 모두 해제해야 D2가 열린다. 장치는 전면 F 상호작용으로 접근·고리 당김 애니메이션을 실행하며 실제 당김 프레임에서 한 번만 해제된다. 기존 소리 전파 시스템에 장치 소리를 전달한다.

## 엔진 적용 보정

- 최종 D01은 `Puzzles/D01_ReferenceRebuild`의 승인된 재제작본이다. 이전 후보를 섞지 않는다.
- Blender→UE FBX의 Y 반사를 확인해 장치 전면, D0 힌지, 대문 좌우를 보정했다.
- UE Interchange가 가져오지 않은 단순 충돌을 보강했다. 캣홀·문틀은 개구를 보존하는 분리 박스를 쓴다.
- 짧은 벽·바닥 마감은 원본 UV 간격을 보존해 절단했다. 규격 에셋을 비균일 스케일로 늘리지 않는다.
- 장치의 고리가 받침대에 묻혀 고양이가 닿지 않던 조립 위치를 전방으로 옮기고 체인을 연결했다. 원본 에셋 메시·리그는 변경하지 않는다.
- 촛불 캡슐은 기존 Stage2와 같은 바닥 여유 2.25cm를 둔다. 몸체 위치는 바닥을 유지한다.
- 전시실 촛불의 순찰을 동상 밀기 경로에서 옮기고, 대문 홀 갑옷 및 창고 고정 촛불의 시작 캡슐과 기둥·소품의 겹침을 해소했다. 11기 모두 저장본 충돌 검사로 확인한다.
- 원본 재질 색을 보존하면서 반대 방향 보조광과 지정 큐브맵 환경광을 추가했다. 어두운 석재 장치 전면과 대문 목재·금속 윤곽을 실제 엔진 캡처로 확인했다.
- 낮은 봉쇄 장치 몸체에는 고양이의 접근 거리에 따른 전용 페이드를 적용한다(155→105cm). 머리·고리 접촉이 가려지지 않으며 멀어지면 원래 표면으로 복원된다. 세 몸체에만 적용하고 충돌과 소리 전파는 보존한다.
- 게임모드에 기본 Pawn이 없는 기존 구조에 맞춰 Stage3에 플레이어 고양이를 배치하고 Player0 소유를 지정한다.

## 이번 구현에서 정한 값과 남은 기획 판단

제한시간 1200초는 난이도 조정을 위한 임시값이다. 최종 대문의 구체적인 개방 연출은 원문에 확정되어 있지 않아, 목표 완료 후 대문에 접근하면 두 문짝이 좌우로 열리게 구현했다. 별도 엔딩 시네마틱을 제작했다는 뜻은 아니다.

원도면에 Stage3 바구니가 없어 배치하지 않았다. 별도 바구니 작업의 Stage3 변형은 기존 납품 폴더에 임포트되어 있다. 표식 회복 수단·적 밀도·방울 필수성·제한시간은 실제 난이도 검토 대상으로 남긴다. 다른 스테이지의 저장 정책은 변경하지 않는다. 특히 Stage2 중간 저장 취소 요구를 유지한다.
