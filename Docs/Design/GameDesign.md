# 《마왕님, 고양이가 도망갑니다》 — 기획 기준 요약

사용자가 2026-09-24에 전달한 전체 기획서를 읽고 정리한 참조 문서입니다. **구현 완료 목록이 아닙니다.** 원문과 그 안의 수정 의견은 [GameDesign_Source.md](GameDesign_Source.md)에 그대로 보존했습니다. 충돌하는 규칙은 아래에 미결정 사항으로 남겼으며 임의로 확정하지 않았습니다.

## 1. 전제와 핵심 경험

- 마왕은 마음에 든 고양이를 성으로 데려왔다. 고양이는 원래 집으로 돌아가려 한다.
- 잠든 마왕이 깨기 전에 탈출해야 하며, 하수인들은 마왕의 고양이가 밖으로 나가지 못하게 한다.
- 핵심: **방울 때문에 들키는 고양이가 그 방울로 추적자를 속여 탈출한다.**
- 플레이 루프: 관찰 → 소리로 통로 비우기 → 조용히 우회 → 필요하면 달려서 탈출.
- 소리는 플레이어가 적의 상태에 능동적으로 개입하는 중심 수단이다. 개별 구간에는 타이밍 회피를 허용하되, 구역 전체를 방울 없이 통과할 수 있게 만들지 않는 것이 원문의 검증 기준이다.

## 2. 플레이어

| 행동 | 소리 | 규칙 |
| --- | --- | --- |
| 살금살금 | 없음 | 기본 이동, 느림. 표식 중에는 소리 小 발생 |
| 달리기 | 中 | 일정 간격으로 소리 발생 |
| 방울 흔들기 | 大 | 자기 위치에서 제자리 유인. 원거리 위치 지정 불가 |
| 은신처 진입·통과 | 없음 | 시야 차단, 진입 모션 필요 |

- 방울 쿨다운은 본문에 **5초**로 명시되지만 후반에는 프로토타입 검증 후 결정으로 남아 있다. 우선 기획값으로만 취급한다.
- 살금살금 < 달리기 < 갑옷의 조사·추적 이동 속도. 갑옷의 평상시 구역 순찰은 느리다.
- 은신처 안에서는 방울을 흔들 수 없다.
- 중간에 새 플레이어 능력을 추가하지 않는다.

## 3. 각성도와 실패

- 전체 게임에서 공유하는 각성도 하나를 사용하며, 기본적으로 시간처럼 상승하고 감소하지 않는다.
- 발각에 따른 추가 상승이나 상승률 증가는 없다. 잡혀서 재시작하는 시간 손실이 이미 페널티다.
- 단계: 깊은 잠 → 뒤척임(촛불 순찰 속도 상승) → 선잠(갑옷 수색 시간 증가, 촛불 시야각 확대) → 각성(실패).
- 숫자 타이머 대신 각성도 게이지를 표시한다. 달 위치, 조명 색조, 마왕의 뒤척임, 종소리도 상태를 전달한다.
- 갑옷에게 잡히면 현재 구역 체크포인트에서 재시작한다. 적 위치·상태, 문, 장치 진행도, 표식은 초기화하고 각성도는 유지한다.
- 각성도 최대 실패도 후반 수정 의견에서는 현재 구역 체크포인트 재시작으로 지정했으나, 이때 각성도 복구 규칙은 미정이다.
- 침실 튜토리얼에서는 실패·표식·각성도 상승을 적용하지 않는다.

## 4. 소리와 연결 그래프

- 소리는 원형 거리 판정이나 벽 관통으로 처리하지 않고 **열린 길을 따라 전파**한다.
- 방 조각과 복도 조각을 노드로 삼는다. 긴 복도는 분할하고, 노드 안의 바닥 재질은 균일하게 한다.
- 공유 공간 연결 구조에 고양이 통과·갑옷 통과·소리 전달 조건을 분리한다. 각 알고리즘에서는 해당 조건에 맞는 그래프를 사용한다.

| 연결부 | 고양이 | 갑옷 | 소리 |
| --- | --- | --- | --- |
| 열린 문·아치 | 통과 | 통과 | 전달 |
| 캣홀 | 통과 | 불가 | 잘 전달 |
| 가구 밑 | 통과 | 불가 | 크게 감쇠 |
| 닫힌 문 | 불가 | 열고 통과 | 차단 |
| 두꺼운 커튼 | 통과 | 통과 | 크게 감쇠 |
| 벽 | 불가 | 불가 | 차단 |

- 갑옷이 연 문은 현재 기획상 열어 둔다. 후반 소리 확산 난이도는 검증 대상이다.
- SoundEvent 필드: 발생자(고양이/갑옷/장치), 종류(방울/발소리/장치작동), 크기(大/中/小), 대상(하수인/고양이).
- 방울·성문 장치 소리는 大, 고양이 달리기는 中, 표식 중 걷기는 小이며 하수인이 듣는다.
- 갑옷 발소리는 中이며 **고양이만** 듣는다. 하수인은 서로의 발소리에 반응하지 않는다.
- 갑옷 발소리가 같은 연결 구조를 따라 도달하면 고양이 귀가 방향을 가리킨다.

## 5. 촛불과 갑옷

### 촛불

- 부채꼴 시야, 벽·큰 가구로 시야 차단, 발견 게이지로 숨을 여유 제공.
- 직접 붙잡지 않는다. 완전 발각 시 표식을 부여한다.
- 소리가 들리면 그 방향으로 **시야만 회전하고 소리 위치로 이동하지 않는다**.
- 놓친 고양이는 마지막 목격 지점을 확인한 뒤 순찰로 복귀한다.
- 순찰형과 넓은 시야를 가진 고정 회전형이 있다.

### 갑옷

- 원문의 수정 의견에 따라 외형상 눈이 없지만 **촛불보다 작은 부채꼴 시야를 갖는다**. 무시야 적으로 단정하지 않는다.
- 소리·촛불 신호·시야를 통해 반응하며 접촉 시 고양이를 붙잡는다.
- 닫힌 문을 열 수 있으나 가구 밑·캣홀에는 들어갈 수 없다.
- 순찰형과, 정해진 구역 안을 순찰하다 소리가 나면 구역을 이탈해 조사하는 변형을 둔다. 원래의 완전 고정 대기형 설명과 구별한다.
- 구역마다 유인 없이는 지나갈 수 없는 지점을 의도한다. 침실의 갑옷 0기 예외는 유지한다.

| 소리를 들은 상태 | 목적지 처리 | 반응 지연 |
| --- | --- | --- |
| 순찰 중 | 조사로 전환 | 적용 |
| 조사 목적지로 이동 중 | 기존보다 큰 소리만 갱신. 같거나 작으면 무시 | 미적용 |
| 도착 후 수색 중 | 크기와 무관하게 갱신 | 미적용 |

- 이 규칙으로 방울 大 유인 직후 달리기 中로 빠져나갈 수 있지만, 도착 후 수색 중에는 달리기가 다시 주의를 끈다. 시야·표식 추적과의 우선순위는 별도 미결정이다.
- 수색은 노드별 수동 지점 2~3개를 도착 위치에서 가까운 순서대로 방문한다. 전부 방문하거나 제한 시간이 끝나면 복귀한다.
- 보지 못하는 고양이의 실제 좌표를 수색 목표로 쓰는 전지적 추적은 금지한다. 수색 지점·순서는 디버그 시각화한다.
- 접촉은 진행 방향 앞 일정 반경이며 정지한 고양이도 잡힌다.

| 구역 | 촛불 | 갑옷 |
| --- | ---: | ---: |
| 마왕의 침실 | 1 | 0 |
| 연회장 | 1 | 1 |
| 마법 회랑 | 2 | 2 |
| 성문 앞 | 2 | 2 |

한 화면의 하수인은 최대 3기. 난이도는 무작정 수를 늘리기보다 순찰 경로와 조합으로 조정한다.

## 6. 표식과 은신

- 촛불 표식은 완전 발각 시 적용하며, 표식 중 살금살금 이동에도 소리 小를 만든다.
- 원문에는 표식 중 근처 갑옷의 지속 추적, 은신처에 숨으면 해제, 일정 시간 유지, 은신처에서 기다리는 페널티가 함께 적혀 있다. 정확한 결합 규칙은 아래 미결정 사항을 따른다.
- 은신처는 가구 밑·캣홀이며, 진입 모션과 **출입구 2개 이상**을 갖는 통과 가능한 우회로다.
- 하수인은 들어올 수 없으며, 갑옷은 입구에서 제한 시간 동안 수색한 뒤 복귀한다.
- 은신처 안 고양이는 실루엣으로 표시한다.

## 7. 맵·챕터

- 복도 중심, 대략 복도 7 : 방 3. 돌 복도는 소리가 멀리 가고 위험하며, 카펫 방은 감쇠와 가구 엄폐를 제공한다.
- 기본 구조는 갈라졌다가 다시 만나는 길이다. 구역마다 시작→출구 사이 독립 경로 2개 이상을 요구한다.
- 고양이·갑옷의 통과 조건은 따로 검증한다. 캣홀로 고양이가 우회하고 갑옷은 돌아가는 비대칭이 중요하다.
- 복도에서 짧은 시간 내 캣홀에 도달할 수 있도록 하며, 막다른 복도에는 반드시 배치한다.
- 구역당 갈림길 2~3개를 기본으로 하고, 갑옷은 복도·촛불은 방 중심으로 배치한다. 출구는 시작 시점에 보이게 한다.
- 독립 레벨 챕터 방식. 연결 복도에서 다음 구역이 조금 보이고, 문 통과 시 챕터 전환·자동 저장. 뒤로 돌아갈 수 없다.
- 구역당 체크포인트는 1개.
- 학습: 침실(이동·시야·방울로 시야 돌리기) → 연회장(갑옷·소리 위험·유인 우회) → 마법 회랑(소리 지형·복합 대응) → 성문(종합).

## 8. 성문

- 바닥 장치는 고양이가 밟고 있는 동안만 개방 진행도가 증가하고 大 소리가 계속 난다.
- 발을 떼면 일부 진행도가 유지된 채 서서히 감소한다. 갑옷은 작동시키지 않는다.
- 완료된 성문은 닫히지 않는다.
- 필수 검증: **재유인 후 장치로 돌아오는 왕복 시간 < 진행도가 유지 하한선까지 감소하는 시간**.
- 새로운 플레이어 능력은 추가하지 않지만, 강제 소리와 진행도 유지 규칙은 성문에서 추가된다.

## 9. 화면과 알고리즘

- 단층 맵·고정 각도 쿼터뷰. 자유 점프·등반·다층 구조 제외. 카메라 쪽 벽을 낮추고 천장을 제거한다.
- 촛불 시야는 바닥 표시하되 벽에 가린 부분을 잘라낸다. 표시와 실제 판정은 일치해야 한다.
- 소리 범위는 실제 전파 계산 결과만 발생 직후 잠깐 표시한다. 임의 원형·상시 표시는 사용하지 않는다.

| 알고리즘 | 용도 |
| --- | --- |
| A* | 갑옷 이동 경로 |
| 다익스트라 | 간선 감쇠를 반영한 소리 전파 |
| BFS | 고양이 그래프에서 간선 수 기준 최근접 은신처 탐색 |
| DFS 기반 Tarjan | 제작 도구에서 브리지 검사. 런타임 3종과 분리 |

독립 경로 검증의 세부 정의는 아래 미결정 사항에 남긴다. BFS 1회만으로 독립 경로 2개를 검증할 수 없다는 원칙은 유지한다.

## 10. 구현 전 확인할 충돌·미결정 사항

아래는 원문을 읽으며 식별한 질문이며, 사용자 승인 없이 새 규칙으로 확정하지 않는다.

1. **각성도 최대 후 재시작:** 전체 각성도 유지·감소 금지와 현재 구역 체크포인트 재시작을 그대로 결합하면 재시작 직후 다시 실패한다. 최대 각성 실패에 한한 복원값·예외가 필요하다.
2. **표식:** 은신처 진입 즉시 해제와 은신처에서 일정 시간 기다려야 한다는 설명이 충돌한다. 자연 만료 여부, 숨기 지속 시간, 커튼 뒤의 해제 자격도 명확히 해야 한다.
3. **시야·신호·소리 우선순위:** 갑옷의 시야 추가와 기존의 실제 좌표 사용 절대 금지 문구를 구분해야 한다. 직접 목격 중 추적, 표식 추적, 목격을 놓친 뒤 수색의 목표 정보와 우선순위가 미정이다.
4. **구역의 필수 유인:** 개별 촛불 구간은 타이밍 회피를 허용한다. 구역 전체의 방울 필수 조건 및 순찰하는 대기형 갑옷으로 유인을 어떻게 보장할지 검증해야 한다.
5. **방울 쿨다운:** 본문 5초와 후반 미정 항목이 병존한다. 5초를 검증 시작값으로 볼지 최종값으로 볼지 확인한다.
6. **독립 경로:** 간선이 겹치지 않는 경로인지, 중간 노드도 공유하지 않는 경로인지 결정해야 한다. 단순히 그래프 어딘가에 브리지가 있다고 시작→출구의 두 경로가 항상 사라지는 것은 아니다. 요구하는 출발·도착점과 그래프별 판정 범위를 정의해야 한다.
7. **기타 원문 미결정:** 갑옷 간 정보 공유, 문을 계속 열어 두었을 때의 밸런스, 촛불 회전 범위, 시야 이탈 후 발견 게이지 처리, 수집물 도입 여부. 수집물을 도입하면 물고 있을 때 방울 불가라는 전제가 있다.

## 11. 구역 완성 시 검증

- 방울을 한 번도 흔들지 않고 구역 전체를 클리어할 수 있는가?
- 서로 다른 돌파 경로가 2개 이상 실제로 가능한가?
- 갑옷이 감지하지 못한 고양이의 좌표를 수색에 사용하는가?
- 하수인이 다른 갑옷의 발소리에 반응하는가?
- 은신처 안에서 방울을 사용할 수 있는가?
- 성문의 나누어 밟기가 실제 왕복 동선에서 성립하는가?

## 문서 사용 범위

이 문서는 앞으로의 게임 설계 참조다. 읽고 보관하라는 요청은 AI·소리·UI·레벨 등 모든 시스템을 즉시 구현하라는 허가가 아니다. 실제 작업에서는 사용자가 지정한 작업 범위와 최신 수정 요청을 우선하고, 기획의 충돌을 몰래 해소하거나 구현 상태로 오인하지 않는다.
