# 스테이지 2 동상·발판·문 — 현행 2026-11-25

정식 맵은 `/Game/Maps/Stage2`, 보조 맵은 `/Game/Maps/SoundTest_Stage2`다. [전체 기획서](GameDesign.md)와 [11월24일 진행 저장 요구](GameplayExpansion_Request_2026-11-24.md)가 우선한다. Stage3 장치 후보와 구분한다.

## 플레이 규칙

- 동상 뒤에서 이동 입력으로 축 방향으로 민다. 별도 버튼·끌어당기기·대각선 밀기는 없다.
- 실제 물체/캐릭터 충돌·지면·역밀기 접근 공간을 검사한다. 방울·바구니 행동 중에는 새 밀기를 시작하지 않는다.
- 약80% 접촉과 소켓 축·높이 조건을 만족하면 정확히 안착한다. 고양이만 발판에 올라서는 작동하지 않는다.
- 눈·발판 변화 → 문 카메라 → 철창이 바닥 아래로 하강 → 카메라·입력 복구. 퍼즐 연출 동안 적과 게임플레이 시간은 정지한다.
- 안착은 고정되며 완료된 링크는 영구 저장한다. 옛 문서의 ‘동상이 벗어나면 닫힘’, ‘문이 위로 상승’은 현행 동작이 아니다.

| 퍼즐 | 동상 / 발판 | 문 |
|---|---|---|
| A | `S2_Prop_Statue_A` / `S2_Prop_Plate_A_Plate` | Gate02, 미로 진입 |
| B | `S2_Prop_Statue_B` / `S2_Prop_Plate_B_Plate` | Gate05, 아래 통로 |
| C | `S2_Prop_Statue_C` / `S2_Prop_Plate_C_Plate` | Gate11, 시작 구간 |

레벨의 `S2_StatuePuzzle.Links`가 실제 참조의 기준이다. B까지 모두 완료해야 출구가 열리는지 여부는 아직 확정되지 않았으며, 현재 출구는 전체 완료 비트를 검사하지 않는다.

## 조정 위치

`/Game/Systems/Interaction/Puzzles/DA_StatuePuzzleSettings` 및 각 Links:

| 값 | 기본/현행 기준 |
|---|---|
| 밀기 상한 | 100cm/s, 기존 이동 모드별 제한 유지 |
| 가속/감속 | 160 / 240cm/s² |
| 접촉 | 약0.8, 축 허용24cm·높이 허용12cm의 코드 기본. 실제 DA/링크 우선 |
| 하강 | 최소280cm, 실제 문 높이+바닥 여유와 비교 |
| 문 속도 / 발판 이동 | 140cm/s / 2cm |
| 바닥 오프셋 | A/B 0, C 20cm |

갑옷 경로·소리는 현재 동상·문 바운드를 동적 장애물로 반영한다. 하강 완료 후 통행 가능한 상태와 미니맵 표시를 일치시킨다.

## 저장·재시도

- 실제 문 하강 완료 후 A/B/C 해당 완료를 한 번 저장한다. 미완료 위치·일반 문 개폐·중복 완료는 새 영구 퍼즐 저장으로 처리하지 않는다.
- 이어하기·포획·시간초과 후 일반 스테이지 시작점에서 저장된 동상·발판·문을 최종 상태로 복원한다.
- 복원은 연출·보상·완료 이벤트·재저장을 반복하지 않는다. 완료 시각표시 등 외형용 복원 이벤트는 별도다.
- 포획/시간초과는 완료를 유지하고 스테이지 시간을 채운다. 설정의 명시적 초기화만 현재 구간 완료를 지운다.
- 동상 되돌리기 UI/F 복구 장치는 최신 플레이 경로에서 제거됐다. `CatrunPuzzleReset`과 네이티브 reset 함수는 잔존 유틸이며, 현재 사용자에게 제공되는 장치라고 안내하지 않는다.

## 확인 수준

이번 감사에서 실제 두 맵의 A/B/C 참조를 로드했고 기존 자동화와 최신 영구 완료/복원 테스트를 실행했다. 초기 복원 단언 실패와 재검사 결과는 [감사 보고서](../Reviews/ProjectAudit_2026-11-25.md)에 보존한다. 함수/fixture 검사는 적을 피하며 모든 퍼즐을 푼 연속 완주와 다르다. 새 스태미나·제한시간 조건의 전체 경로 수용은 남아 있다.
