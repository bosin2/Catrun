# 스테이지 2 동상·발판·문 구현

2026-11-03. 적용 맵: `/Game/Maps/Stage2`, `/Game/Maps/SoundTest_Stage2`.
스테이지 2의 동상 시스템은 유지한다. 스테이지 3의 장치 교체와 무관하다.

## 조작과 규칙

- 동상 뒤에 붙어 이동키를 누르면 해당 축으로 민다. 당기기·대각선 밀기는 지원하지 않는다. 조작 방식은 사용자 확정이다.
- 벽·다른 동상·캐릭터가 앞을 막거나 받칠 바닥이 없으면 이동하지 않는다. 방울·바구니 동작 중에는 밀지 않는다.
- 동상 중심이 발판 중앙 허용 범위에 들어가면 발판이 내려가고 연결된 철문이 위로 열린다. 고양이만 올라가서는 작동하지 않는다.
- 동상이 벗어나면 발판이 복원되고 문이 닫힌다. 문 아래 고양이·갑옷·동상이 있으면 닫힘을 보류한다.
- **F: 방 안의 푸른 복구 장치 사용.** 해당 방 동상만 원위치로 복구한다. 적·표식·다른 방 동상은 유지하며, 복구 위치에 플레이어나 다른 동상이 있으면 거부한다. 장치는 각 퍼즐을 다시 풀 수 있는 쪽에 배치한다.
- 전체 재시작은 Esc/P 일시정지 메뉴에서 진행 포기를 확인한 뒤 실행한다. R은 기본 비활성인 에디터 개발 기능으로 분리했다.
- 밀기 속도·중앙 허용 범위·문 속도·발판 눌림 깊이는 초기 튜닝값이며 플레이 피드백으로 조정한다. 동상 밀기의 별도 소음·전용 애니메이션은 이번에 추가하지 않았다.

## 실제 맵 연결

| 퍼즐 | 동상 | 발판 | 열리는 문 |
| --- | --- | --- | --- |
| A | S2_Prop_Statue_A | S2_Prop_Plate_A_Plate | S2_Gate_02_Bars: 미로 진입 |
| B | S2_Prop_Statue_B | S2_Prop_Plate_B_Plate | S2_Gate_05_Bars: 방3 아래 통로 |
| C | S2_Prop_Statue_C | S2_Prop_Plate_C_Plate | S2_Gate_11_Bars: 입구 연습 구간 출구 |

현재 맵에는 A/B/C 세 쌍이 있다. 다운로드 폴더의 옛 2쌍 도면으로 덮어쓰지 않았다. 두 맵 사이 동상 A의 배치 차이도 유지했다.

`S2_StatuePuzzle` 액터의 Links에서 참조를 편집한다. 기존 메시 액터와 초기 위치·회전·크기는 유지하고 이동할 메시의 Mobility/Collision 및 동적 그리드 처리를 설정했다.

## C++·BP·데이터 역할

- `ACatrunStatuePuzzle`: 밀기 접촉·장애물·지면 검사, 발판 작동, 안전한 문 이동, 방별 동상 복구.
- `ACatrunPuzzleReset`: F 상호작용의 거리·차폐·행동 상태 검사. 기존 바구니 상호작용 진입점을 공유하며, 숨은 상태에서는 바구니 탈출을 우선한다.
- 기존 메시와 레벨 참조: 외형 및 배치. 추가 연출은 BP 자식의 `OnPlateChanged` 이벤트로 연결할 수 있다.
- `/Game/Systems/Interaction/Puzzles/DA_StatuePuzzleSettings`: 공유 튜닝. 기본 밀기 상한 100cm/s(고양이 이동 속도를 넘지 않음), 발판 중심 허용 18cm, 눌림 2cm, 문 상승 280cm·140cm/s.
- `SoundGridManager`와 갑옷 경로는 현재 동상·철문 위치를 동적 장애물로 읽는다. 동상이 이동한 자리에 이전 장애물이 남지 않는다. 상승 중인 문은 갑옷이 통과할 높이가 확보될 때까지 경로·소리를 보수적으로 차단한다.

## 검증 및 남은 범위

- C++ 에디터 타깃 빌드, 자동 테스트 10개(기존 6 + 퍼즐 4).
- 실제 두 맵의 A/B/C 경로: 총 6개 모두 밀기 함수와 실제 지형 충돌을 거쳐 발판 작동·문 280cm 상승 확인. 이 검사는 고양이를 밀기 접촉 위치로 배치하는 자동 검사다.
- 일반 PIE에서 고양이에게 이동 입력을 공급해 런타임 Tick으로 동상이 이동하는지 별도 검사한다. 함수 직접 호출 검사와 구분한다.
- 진단 결과: `Saved/Stage2/Automation/index.json`, `routes.json`, `pie-input.json`. 검사 스크립트는 테스트 위치를 맵에 저장하지 않는다.
- 화면·음향·애니메이션 체감, 적을 피하면서 전체 퍼즐을 푸는 완주, 모든 출입문·탈출 조건, 1→2 연결·시네마틱은 별도 후속 작업이다. **이 작업으로 스테이지 2 전체가 완성된 것은 아니다.**

맵 연결 재현: `Scripts/Stage2/setup_statue_puzzles.py`. 기존 맵 백업은 `Saved/Stage2/Backups/`에 있다. 검증용 실행은 `UnrealEditor-Cmd`의 `-ExecutePythonScript`를 사용해야 물리 장면이 준비된다.
