# 심플한 고딕 HUD

사용자 첨부 레퍼런스(2026-11-25)에 따라 배치와 디테일을 확정하고 구현했다. UI Design System 스킬의 공통 색상 토큰과 컴포넌트 상태 구분 원칙을 적용한다.

## 화면 구성

- 상단 중앙: 원형 앤틱 시계. 황동 이중 테두리, 양피지색 문자판, 숫자 없는 12개 눈금, 작은 첨두 장식 하나. 화려한 문양과 맥박 효과는 사용하지 않는다.
- 시계 긴 바늘은 스테이지 전체 제한 시간 동안 한 바퀴 진행한다. 남은 시간은 바깥 링으로 함께 표현한다. 경고·긴급 기준은 기존 게임플레이 값을 읽는다. 튜토리얼은 정적인 초승달로 시간 제한 없음을 구분한다.
- 좌하단: 세이지색 세로 스태미나 막대와 고양이 목방울 아이콘. 방울 충전은 원형 링, 사용 불가는 어두운 아이콘과 사선으로 구분한다. 스태미나 고갈은 비어 있는 막대와 작은 붉은 끝선으로 표현한다.
- 우상단: 기존 미니맵의 위치·크기·Tab 확대를 유지하고 프레임과 도면 색을 통일한다. 마커는 아래 후속 요구를 반영한다.
- `100`, 남은 초, `mm:ss`, 준비/충전 중 문구와 기존 상태 카드 제목을 상시 HUD에서 제거한다. 기존 튜토리얼 안내와 상호작용 안내는 별개다.

## 구현 경계

공통 색상은 `Source/Catrun/UI/CatrunHUDStyle.h`에서 관리한다. 상태 HUD는 기존 `WBP_PlayerStatus`의 네이티브 부모가 Slate 벡터로 그린다. 기존 카드와 텍스트는 숨기고 비우며, ProgressBar 바인딩은 기존 소비자와 테스트를 위해 상태를 계속 갱신한다. 위젯 디자이너에서도 같은 처리를 한다.

시계·스태미나·방울 수치는 각각 기존 LevelFlow/Sprint/Bell 소유자에서 읽는다. 소모, 회복, 제한시간, 재사용 대기시간을 변경하지 않는다. 설정·시네마틱·레벨 전환의 기존 HUD 숨김 조건을 유지한다. 바이너리 에셋과 맵을 덮어쓰지 않는다.

## 검증

- `Catrun.UI.Status.MinimalPresentation`: 실제 저장된 Blueprint의 텍스트 제거·포커스 확인. `-CatrunHUDRender`에서 상태별·해상도별 Slate 렌더와 픽셀 비교, 숨김 확인.
- `Catrun.UI.Status.LiveStage`: 실제 게임 월드의 HUD 단일 인스턴스·게임플레이 상태 연결·숫자 제거 확인과 화면 캡처.
- 기존 `Catrun.UI.GameplayHUD` 및 `Catrun.UI.Minimap` 검사로 표시 조건과 지도 동작을 확인한다.

검증 결과와 범위는 별도 리뷰 문서에 기록한다. 위 항목은 검사 정의이며 실행 성공을 뜻하지 않는다.

## 후속 수정: 미니맵 마커

사용자 지시: 촛불 단순화, 고양이 노랑, 갑옷 붉은 이모지형, 가독성 개선.

| 대상 | 형태와 색 | 기본 크기 |
|---|---|---|
| 고양이 | 얼굴 묘사 없는 노란 귀 실루엣 | 22 Slate 단위 |
| 갑옷 | 가는 틈 하나만 남긴 붉은 투구 실루엣 | 20 Slate 단위 |
| 촛불 | 단색 불꽃 하나 | 18 Slate 단위 |

최신 사용자 정정: 이전 이모지의 디테일이 과하다. 매우 단순하고 약간 투명한 표현으로 바꾼다. 눈·코·하이라이트·외곽선을 전부 제거하고 단색 78% 불투명도로 그린다. 미니맵 프레임 바탕은 42%, 내부 추가 바탕은 8%, 도면은 72% 불투명도다. 테두리는 1 Slate 단위다. 고양이 최상위 그리기 순서와 실제 위치, Tab 확대 시 기존 0.85배 축소·중심 정렬을 유지한다.

`CatrunMinimapMarkerWidget`의 네이티브 벡터 아이콘을 사용하여 시스템 이모지 폰트 차이를 없앴다. 저장된 미니맵 패널을 초기화할 때 세 클래스만 교체하며, 출구·문·캣홀 마커는 기존 설정을 유지한다. 색상은 `CatrunHUDStyle.h`에서 관리한다.
