# 플레이 흐름과 재시작 — 현행 2026-11-25

이 문서는 정식 맵과 최신 시간·저장 요구에 맞춰 갱신했다. 전체 기준은 [GameDesign.md](GameDesign.md), 검증 상태는 [전체 감사](../Reviews/ProjectAudit_2026-11-25.md)를 따른다. 이전 SoundTest 경로·C 체크포인트·실패 시 모든 퍼즐 초기화 설명은 현행 정책이 아니다.

| 구간 | 정식 실행 맵 | 완료·다음 구간 |
|---|---|---|
| 시작 | `/Game/Maps/MainMenu` | 새 게임 → 원래 튜토리얼 인트로 |
| 튜토리얼 | `/Game/Maps/Tutorial` | 원래 계단 출구 → Stage1, `FromTutorial` 유지 |
| Stage1 | `/Game/Maps/Stage1` | 포털 출발 연출 → Stage2, 승인 경로만 도착 연출 |
| Stage2 | `/Game/Maps/Stage2` | 열린 Gate00 뒤 출구 복도 진입 → 같은 맵에서 완료 안내 |

`Config/DefaultGame.ini`의 Stages 및 MapsToCook, `DefaultEngine.ini`의 GameDefaultMap이 이 경로를 사용한다. Stage3는 아직 포함되지 않는다. Content Browser는 `Content/Maps`, 검색어는 `Tutorial`, `Stage1`, `Stage2`다.

## 전환·완료

- 기존 BP가 인트로·계단·포털·페이드를 소유하고 공통 LevelFlow가 실제 전환·중복 방지·실패 복구를 담당한다.
- 출구는 실제 플레이어와 적절한 행동 상태·진입 깊이를 확인한다. 포획·시간초과·출구가 전환을 중복 소유하지 않는다.
- Stage1 승인 출구 복도는 표식·추적을 정리하는 안전 예외다. 단순히 소리가 안 나는 곳이라는 의미가 아니다.
- Stage2 완료 후 새 포획은 막고 이동은 유지한다. 완성 게임의 최종 엔딩으로 확정하지 않는다.
- Stage2 출구에는 A/B/C 전체 완료 조건이 없다. B 퍼즐 필수 여부는 기획 결정 대상이다.

## 재시작·저장

| 행동 | 시작 위치 | 완료 퍼즐 | 남은 시간 |
|---|---|---|---|
| 이어하기 | 해당 구간 일반 시작점 | 저장된 완료 유지 | 저장값 유지 |
| 포획·시간초과 | 현재 구간 일반 시작점 | 완료 유지 | 현재 구간 배분 재충전 |
| 설정의 현재 스테이지 처음부터 | 현재 구간 일반 시작점 | 현재 구간만 초기화 | 현재 구간 배분 재충전 |
| 새 게임 | 튜토리얼 | 새 진행 초기화, 최고 해금 유지 | 새 구간 배분 |

재시작 때 적·표식·미완료 동상·일반 문 등은 새 월드 상태로 돌아간다. 완료한 Stage2 동상·발판·문은 조용히 최종 상태로 복원한다. C/Gate11 좌표로 이동시키지 않는다. 다른 구간 진행·최고 해금·튜토리얼 안내 완료는 명시적 현재구간 리셋으로 제거하지 않는다.

시간은 Stage1 600초/Stage2 900초의 임시값이다. 튜토리얼은 시간초과가 없다. 로딩·시네마틱·퍼즐 연출·설정·실패 중 정지하고 일반 방울·은신·관찰·스태미나 회복 중에는 흐른다. 메뉴 복귀·정상 종료 때 최신 시간을 저장한다.

## 조작·UI

- 방울 Space, 상호작용 F, 달리기 Shift, 살금살금 Ctrl, 지도 확대 Tab 유지.
- Esc/P 공통 설정 경로. 에디터 Esc의 PIE 종료와 구분한다.
- R 즉시 전체 재시작과 동상 되돌리기 버튼은 일반 플레이에서 제공하지 않는다.
- 설정의 `스테이지 처음부터 다시 시작`은 확인/취소 후 실행한다.
- 튜토리얼 원래 안내·연출을 보존한다. 새 자원 HUD는 기존 안내를 대체하지 않는다.

## 검사 맵 주의

`SoundTest_*`는 보조 맵이다. 현재 Tutorial/Stage2 미러에는 정식 맵의 캣홀 방울 금지 영역이 빠져 있어 정식 맵과 같은 조건이 아니다. 이전 검사 스크립트가 특정 미러나 옛 복구 장치를 가정할 수 있으므로 실행 전 대상·규칙을 확인한다. 과거 PIE 성공 기록은 해당 버전의 증거이며 최신 기능/전체 완주 성공으로 소급하지 않는다.
