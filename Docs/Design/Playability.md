# 튜토리얼 안내와 방별 복구

2026-11-03 사용자 승인: 물리 장치로 해당 방 동상을 복구하고, 튜토리얼의 현재 크리쳐 배치에 맞춰 안내·화면을 추가한다. 11월 4일 수정 요청으로 튜토리얼에 추가했던 UI·배치 변경은 철회하고 기존 연출·안내를 복구했다. 각성도·스테이지 3 기획은 이번 변경에 포함하지 않는다.

## 플레이 방법

- MainMenu의 시작 버튼 → SoundTest_Tutorial → SoundTest_Stage1 → SoundTest_Stage2.
- WASD 이동, Ctrl 살금살금, Shift 달리기, Q 방울, F 바구니/복구 장치.
- 스테이지 1·2에서는 Esc/P로 일시정지 메뉴를 열고 계속하기·현재 구간 재시작·시작 메뉴 복귀를 선택한다. 재시작은 확인 버튼을 다시 눌러야 실행된다. 튜토리얼은 기존 UI만 사용한다.
- R은 일반 플레이에서 동작하지 않는다. 개발자가 에디터 PIE에서 `catrun.DebugRestart 1`을 명시한 경우에만 사용할 수 있다. 기본값 0, 패키지에서는 제외.
- 완료한 스테이지 2에서는 이동을 유지하고 HUD에 완료를 표시한다.

## 동상 복구

Stage2와 SoundTest_Stage2에 A/B/C 장치를 배치했다. 근처에서 F를 누르면 연결된 동상 하나만 초기 위치로 이동한다. 표식·적 상태·플레이어 위치·다른 동상은 초기화하지 않는다. 문은 발판 상태에 따라 기존 속도로 닫히고, 문 아래 캐릭터가 있으면 닫힘을 보류한다.

| 장치 | 위치 cm | 대상 |
|---|---|---|
| S2_Recovery_A | 1820, 3010, 1 | 동상 A |
| S2_Recovery_B | 700, 1920, 1 | 동상 B |
| S2_Recovery_C | 1650, 3830, 1 | 입구 연습 동상 C |

105cm 이내이며 벽에 가려지지 않아야 한다. 복구될 자리를 고양이·다른 동상 등이 차지하면 거부하고 이유를 표시한다. 포획·전환·완료 상태에서는 복구하지 않는다. 장치는 이동·소리 경로를 막지 않는 낮은 원형 받침과 푸른 조명으로 표시한다. 최종 아트는 교체 가능하다.

## 튜토리얼 복구 (2026-11-04)

사용자 지시에 따라 추가했던 설명 UI·7개 안내 구역·복도 문 시작 열림·추가 방울 금지 구역을 철회했다. `BP_TutorialIntro`는 변경 전 원본으로 복구하여 기존 `WBP_Tutorial_KeyHint` 생성과 표시를 되살렸다. 튜토리얼에서는 새 C++ PlayHUD를 생성하지 않는다. 기존 인트로·계단 시네마틱과 그 자체의 페이드는 유지하며, 공통 레벨 전환에서 추가했던 페이드는 제거한다.

고양이·촛불·갑옷·바구니 위치는 원래 배치다. `setup_playability.py`는 이제 Stage2만 처리하며 튜토리얼 에셋을 수정하지 않는다.

추가 사용자 확정: 촛불에 발각되면 기준 거리 내 갑옷은 벽 너머라도 표식에 반응한다. 이동 경로는 벽을 우회하고 닫힌 문을 열어 통과한다. 튜토리얼의 `bMarkAttractsArmors`를 켜며 공통 호출 거리는 `DA_SoundSettings`의 Mark 범주에서 조절한다. 표식 대상 선정은 소리 전파 여부에 의존하지 않는다.

이번 복구와 실제 트리거 검사 기록은 `Saved/Restoration`에 저장한다. [11월 4일 복구·검증 기록](../Reviews/TutorialRestoration_2026-11-04.md)을 참조한다. 아래 11월 3일의 이전 검증은 당시 구현에 대한 기록이며, 종료 함수를 직접 호출한 검사는 시네마틱 연결의 검증으로 사용하지 않는다.
