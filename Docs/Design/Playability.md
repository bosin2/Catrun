# 튜토리얼 안내와 플레이 방법 — 현행 2026-11-25

전체 규칙은 [GameDesign.md](GameDesign.md), 전환·재시작은 [PlayFlow.md](PlayFlow.md), 퍼즐은 [Stage2StatuePuzzle.md](Stage2StatuePuzzle.md)를 따른다.

- WASD 이동, Ctrl 살금살금, Shift 달리기, **Space 방울**, F 바구니, Tab 유지 지도 확대. 예전 문서의 Q 방울은 잘못된 안내였다.
- 튜토리얼의 원래 인트로·조작 안내·계단 연출을 보존한다. 추가 설명 HUD로 원래 표현을 대체하지 않는다.
- 튜토리얼에는 제한시간 실패가 없다. 다음 스테이지부터 시간이 흐른다는 안내와 새 자원 HUD를 통합한다.
- 캣홀 주변에서는 방울이 금지된다. 금지 구역의 실제 배치는 정식 맵을 기준으로 확인한다.
- 바구니의 입구 방향·접근 공간·지면이 유효할 때 F로 들어가며, 숨은 상태의 F는 안전한 탈출을 시도한다. 들어가는 단계에서 표식 안전 판정이 시작된다.
- 현재 구간을 처음부터 시작하려면 설정에서 확인 후 실행한다. 일반 R 재시작이나 동상 되돌리기 버튼은 제공하지 않는다.
- 과거 F 방별 복구 받침대는 현재 제작 요구에 따라 제거됐다. 동상이 막히지 않도록 역밀기 공간을 확보하는 설계와 현재구간 리셋을 사용한다.

최신 HUD/스태미나/시간/저장 통합의 실행 증거와 한계는 [2026-11-25 감사](../Reviews/ProjectAudit_2026-11-25.md)에 있다. 이전 `setup_playability.py` 등은 과거 배치를 재생성하는 도구일 수 있으므로 현재 맵에 무조건 재적용하지 않는다. 실제 키·입력·방향별 접근과 전체 완주는 별도 수용 항목이다.
