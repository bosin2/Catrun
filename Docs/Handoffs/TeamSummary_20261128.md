# 11/28 수정 요약

- **순찰 촛불**: 이동 순찰 중에는 좌우로 돌지 않고 걷는 방향만 봄. 앞에 동상·갑옷이 있으면 되돌아감. (Stage2 촛불은 아직 순찰 꺼져 있음)
- **최종 성문**: 문이 다 열린 뒤에도 계속되던 화면 진동 수정.
- **레버 소리 범위**: Stage3Objectives의 `ReleaseSoundBudget`로 따로 조절. 현재 500cm. 0이면 Stage3 큰 소리 기본값 1800cm.
- **개발 탭**(Esc → 설정 → 개발): "갑옷 이동 영역 보기"(파랑 = 지나갈 수 있음, 주황 = 갑옷에게 좁음), "스태미나 무제한" 추가.
- **소리 로그**: 어떤 소리를 어느 갑옷이 어디서 들었는지 로그에 이름·위치로 남김.
- **맵 객체 위치**: 맵 로직 반영을 위해 Stage1·2·3 객체 위치 수정 (별도 작업).
- 코드는 C++만 수정(BP 수정 없음). 테스트 184개 통과.
