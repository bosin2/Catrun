# 미니맵 누르기 확대·주변 지도·금속 프레임

사용자 요청: Tab을 누르는 동안만 살짝 확대, 놓으면 복귀. 평소에는 고양이 주변을 게임 시야보다 넓게 표시. 배경은 더 투명하게, 테두리는 빛나는 금속 느낌. 중앙 전체 지도와 Tab 안내는 사용하지 않는다.

## 저장한 동작과 조절 위치

- `UCatrunMinimapWidget`의 매 프레임 입력 확인으로 누르기/놓기를 반영한다. 기존 누름 토글과 액터 입력 스택 등록을 제거했다. 포커스·입력 가능 여부·공통 HUD 숨김 정책을 적용하고 설정 진입도 즉시 접는다. 설정창의 Tab 탐색은 그대로다.
- `WBP_Minimap_Floorplan`의 `HoldSizeMultiplier=1.25`: 기본240에서 누르는 동안300으로 확대한다. 우상단 앵커/정렬과24 여백을 유지하며 작은 창에서는 들어갈 크기로 제한한다.
- `NeighborhoodCoverage=1.30`: 실제 카메라 투영/화면 비율로 계산한 시야를 포함하도록 고양이 중심 주변 범위를 설정한다. 기본/확대에서 같은 주변 범위를 사용한다. 카메라 방향/기울기와 지도·마커 위치를 일치시키고 아이콘은 똑바로 유지한다. 범위 밖 마커는 숨기며 이미지도 지도 내부에서 자른다.
- `MapBackground` 불투명도0.68. 새 `Textures/T_Minimap_FloorplanFrame`은 직접 생성한64px PNG의9슬라이스 이미지다. 얇은 은청색 베벨/하이라이트,2단위 테두리, 약0.10 배경을 사용한다. `MinimapFrame` 패딩10 유지. 기존 고양이/갑옷/촛불 마커 PNG는 원본과 바이트가 같다.
- 크기/주변 범위는 위젯 BP 클래스 기본값, 지도 불투명도와 프레임 틴트는 해당 UMG 속성에서 조절한다. 프레임에 구워진 색·두께·배경은 작성 스크립트 상수와 원본 PNG를 변경하고 의도적으로 재임포트/해시를 갱신해야 한다. 상수만 바꿔 재실행하면 기존 자산 보호용 해시 검사가 중단한다.

작성 도구: `Scripts/Menu/author_minimap_hold_neighborhood.py`. 읽기 전용 감사 인수: `-catrunMinimapHoldAudit`. 기존 작성/카메라 투영 스크립트도 현재 프레임 로직을 사용한다. 게임 맵, 감지/소리 전파, 오디오 작업에는 변경이 없다.

전체 검사의 경고는 기존 실패 복구·AI 검증 경고4종과 RHI를 켠 광범위 테스트에서 발생한 reserved resource virtual size 경고1종이다. 미니맵 최종 검사에는 경고가 없었다. 렌더 예산/경고를 숨기거나 제품 그래픽 설정을 바꾸지 않았다.

`Preview/compact.png`, `Preview/held.png`는 저장된 실제 위젯/Stage2 도면을 가상 Slate 창에 그린 결과다. 카메라·배우 위치는 검사 고정값이며 실제 게임 플레이 캡처가 아니다. Tab 상태 전환 검사는 합성 입력 표본을 사용한다. 실제 키보드 입력·Alt+Tab 반복·손플레이는 이번에 수행하지 않았다. 포커스 상실 시 엔진이 키 상태를 지우므로 복귀 후 물리 키를 계속 누른 상태의 반복 입력은 다시 확대할 수 있다. 새로운 물리적 키 떼기까지 재확대를 막는다는 보장은 하지 않는다.

## 시각 결함을 발견하고 처리한 근거

초기 UI 머티리얼은 저장/컴파일/구조 검사를 통과했지만 실제 렌더에서 프레임이 전부 알파0이었다. PSO 건너뛰기 해제, 메모리에서만 단색 출력, 공식 머티리얼 setter 비교도 해결하지 못했다. 동일한 실제 Border에 기본 텍스처를 연결한 비교에서는 정상적으로 그려졌다. 정확한 엔진 내부 머티리얼 누락 원인은 확정하지 않았으며, 제품 프레임을 정상 렌더가 검증된 일반 텍스처 방식으로 구현했다. 진단용 변경은 저장하지 않았고 원본 해시를 확인했다.

초기 이미지 생성 검사만으로 누락을 놓쳤으므로 최종 검사에는 실제 프레임 가장자리/투명 패딩의 픽셀 검증을 추가했다. 이 검사는 누락 프레임과 불투명 흰색 진단 프레임을 모두 실패로 검출하고 최종 프레임에서 통과했다.

## 진행 중 판단과 보존

- 이전에 허용된 main 작업 폴더에서 수정하고 커밋/푸시는 하지 않았다. 잘못되면 검토 가능한 로컬 변경으로 되돌릴 수 있다.
- 모호한 ‘살짝/더 넓게’는 조절 가능한1.25/1.30 기본값으로 정했다. 필요하면 위젯 기본값에서 조정한다.
- API 이름을 확정한 뒤 서로 다른 C++/Python 소스 작업을 병행했다. 빌드와 실제 에셋 쓰기는 메인 에이전트만 순서대로 실행하고 통합 검사했다.
- 현재 사용 중인 다른 프로젝트 `Study_Unreal_Shooter` 에디터는 조작하거나 종료하지 않았다. Catrun만 숨김 별도 프로세스로 검사했다. 최초 작성 프로세스의8000 포트 충돌 이후 해당 검사 프로세스에서만 MCP 자동 시작을 끄는 임시 인수를 사용했다. 다른 프로젝트의 MCP나 프로젝트 설정은 바꾸지 않았다.
- 물리적 키 재입력 정책을 추가하는 대신 현재 요청의 누르는 동안 확대/포커스 상실 시 축소 계약을 유지했다. 실제 포커스 입력 검증 한계는 위에 적었다.
- 새 머티리얼 방식 대신 직접 만든 프레임 텍스처를 선택했다. 셰이더 매개변수 편집은 없어졌으나 일반 UMG 이미지로 확실히 표시되고 색상 틴트를 조절할 수 있다.
- 작업 증거/리뷰 파일은 아직 커밋되지 않은 작업의 재개 근거이므로 로컬 `.superpowers/sdd/2026-11-16-minimap-hold-neighborhood/`에 보존한다. 기존 오디오/도구 설정과 사용자 저장 파일은 별도 보존한다.

마무리: 이번에 만든 미사용 머티리얼만 참조 패키지0개를 확인하고 Saved에 백업한 뒤 제거했다(`Cleanup01.log`). Catrun 검사 프로세스가 모두 종료된 후 사용자 저장/설정3파일의 원본 SHA256 일치를 확인했다(`restored-state.json`). 기존 미니맵20패키지 중 의도한 위젯만 변경됐고 나머지는 해시가 동일하다. 다른 프로젝트의 에디터들은 열려 있는 상태로 보존했다.
