## 재실행 시 보존

주 레이아웃 적용기는 이미 반영된 맵을 읽기 전용으로 확인한다. 두 번 배치했을 때 액터·컴포넌트 좌표와 음향 그리드 해시가 일치했다. 미니맵 작성기는 유효한 사용자 지정 배율·전환 시간을 유지하고, 연출 작성기는 기존 바인딩을 확인한 후 변경이 필요한 패키지만 저장한다.

최종 콜드 검사 `FinalCold03`은 새 에디터에서 여섯 스크립트를 차례로 실행하고 두 Stage1 맵의 경고 수정을 다시 확인한 후 종료 코드 0을 반환했다. `final_cold_integrity.json`의 검사 대상 파일은 47개였으며, 검토자가 현재 디스크의 SHA-256을 별도로 계산해 47개 모두 일치를 확인했다. 최초 콜드 비교에서 순서가 달라진 것은 고양이 애니메이션 섹션 여섯 개의 열거 순서였다. 그 목록만 정규화했을 때 두 기록의 전체 시퀀스 검사값이 같았다.

**별도 설정 스크립트의 재실행 문제를 수정했다.** 초기 버전은 `Scripts/LevelFlow/setup_playability.py`를 호출할 때마다 두 맵의 안내문을 덮어쓰고 저장했다. 수정본은 예전 복구 안내 문장과 정확히 일치할 때만 교체하며, 액터 제거 또는 문구 교체가 발생한 맵만 저장한다. 검토자가 엔진 API 대역을 사용해 실제 스크립트 진입점을 두 차례 호출했다. 사용자 지정 문구를 보존했고 예전 문구와 버튼이 있던 맵만 처음에 한 차례 저장했으며, 두 번째 호출의 저장 횟수는 0이었다. 최종본은 맵을 떠나기 전에 액터 목록을 해제한다. 엔진 API 대역의 약한 참조로 다음 맵을 로드할 때 이전 액터 객체가 남지 않았음을 확인했다.

- 최초 도착 PIE `ArrivalRuntime/20261123-112211-377339/report.json`에서 전환 직전 338프레임의 카메라는 목표에 도달한 뒤, 344프레임의 첫 블렌드 표본에서 이전 위치 방향으로 4.59cm, 투영 너비 14.89cm 되돌아갔다. 이 실행은 제목 검사 도달 전에 중단됐다. 해당 문제를 담당자에게 전달했다.
