## 검사 한계와 별도 문제

- 전체 DX12 자동화 `FinalAutomation01`은 다수 임시 월드를 생성한 뒤 가상 예약량 258GB/256GB 경고와 `DXGI_ERROR_DRIVER_INTERNAL_ERROR`로 중단됐다. 당시 로컬 VRAM 사용은 약 3.2/7.2GB여서 VRAM 고갈이라고 단정하지 않는다. 이후 논리 검사는 NullRHI, 실제 화면/맵은 별도 DX12 실행으로 분리했다. 엔진/드라이버 문제 해결을 주장하지 않는다.
- 복도 바깥 격자 범위의 발소리 `no floor cell` 및 기존 Python 타입명 충돌 경고는 별개로 남는다. 복도 재인식 차단은 양의 전파 예산을 가진 방울과 지연 소리를 사용해 검증했다.
- 손으로 전체 게임을 무중단 완주한 검사가 아니다. 실제 PIE의 프로그램 입력, 제한된 초기 fixture, 시퀀스 렌더/충돌/전파 검사를 구분해서 기록한다.
