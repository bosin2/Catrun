## 2. 실행 환경
- 감사 대상: HEAD `ceddc03` + 미커밋 `Stage2.umap`(23:16). 보고서 작성 시점의 main은 `d7d864f`로, 밤샘 통합이 합쳐진 상태다. 따라서 이 결과는 `d7d864f`에서 다시 확인해야 한다. 이 파일의 중간본은 다른 세션의 통합 커밋 `3d9f87c`에 들어갔고, 이 최종본은 미커밋이다.
- 재생 대상: 시작 직후 `R/Snapshot/Catrun`에 복사(맵·Config 해시가 기준과 동일)해 재생했다. 사용자 작업 에디터(PID 43664)는 23:37:50에 이미 정상 종료된 상태였고 건드리지 않았다.

- 다른 세션과 메모리를 나눠 쓰느라 두 번 메모리 부족으로 충돌했다(tut 1차, probe). 이후 실행은 공용 대기열 `Saved/UESlot/ue_slot.py`로 한 번에 하나씩 돌렸다.
- 캡처 무결성: 일부 프레임은 크기가 다른 에디터 뷰포트가 섞여 도구에서 자동 제외했다(예: capture n2·4·13·503·570·571, elev n1385~1387, stage2 n1324, stage2b n259). 근거로 쓰지 않았다. 연속 캡처 구간의 누락 목록은 각 run의 sheet 출력에 있다.

  - UMG 애니메이션은 실시간 기반이라 제목·안내의 지속 시간은 판정하지 않았다.

- 입력 주입: Esc·Tab은 Slate 전처리기라 주입되지 않는다. Esc는 설정 API로 대체했고, Tab 확대는 미재생이다. 나머지 키는 `PlayerController.InputKey`로 넣었다.
- **손플레이 완주가 아니다.** fixture는 다음과 같다(이벤트는 summary.txt에 기록).
  - 위치 순간이동, 동상 밀기 구간 사이 재배치, edge의 갑옷 이동.
  - `catrun.NoArmorCapture`: exit·exitinput·stairs·stage2·stage2b·elev·elev_dx12·stage3b·mark.
  - 시간 예산 축소(메모리 값): timeout 24초, edge 30초.
  - 메뉴 시작은 버튼 delegate 호출.
- 스킬:
