# Stage2 탈출구와 main 게시 — 2026-11-11

사용자는 앞선 바구니/문 수정을 main에 게시하고, Stage2 탈출구 문을 열어 바닥을 이어 “스테이지1 출구처럼” 약간 가려 달라고 요청했다. Computer Use·PIE·화면 입력은 하지 않았다.

## 변경

- Stage2/SoundTest_Stage2의 `S2_Gate_00_Bars`를 z=-261cm로 내려 상단을 바닥15cm 아래로 두고 충돌과 SoundWall 태그를 제거했다. 기존 문틀·문턱은 그대로다.
- X615..815, Y-415..-15에 폭200cm/길이400cm의 석재 바닥을 이었다. 바닥 높이는 기존 문턱과 같은 Z0이다. Stage1에 쓰인 벽·천장·암흑 끝벽·가림·검은 안개 재질을 재사용했다. 새 머티리얼/시퀀스/포털은 만들지 않았다. 맵마다 `S2_ExitCorridor_*` 액터15개다.
- 옆벽·끝벽은 실제 충돌과 SoundWall을 갖는다. 안개·바깥 가림은 NoCollision이며, 바닥 타일2개만 SoundFloor로 지정했다. 천장과 받침을 바닥으로 잘못 인식하지 않게 했다.
- `Flow_Stage2Complete`를 `(715,-80,65)`로 이동하고 기존 Extent `(65,30,80)`에 `bRequireCenterInside=true`를 저장했다. 캣 중심이 문을 지난 Y=-50 이하에서 완료 조건에 들어간다. 기존 최종 구간 완료 규칙/같은 맵 유지/Stage3 미연결은 그대로다.
- 기존 바구니, 일반 문04/07의 열린 상태, 석상 문02/05/11과 퍼즐 설정은 보존했다. 원래 액터 중 변경한 것은 Gate00과 완료 트리거뿐이다.

## 검사

`Scripts/GameplayRepair/repair_stage2_exit.py`는 probe/verify/apply/audit를 구분한다. 검증은 메모리에서 배치 후 폐기하며, 실제 저장은 별도 보고서의 소스/콘텐츠 해시가 일치할 때만 허용한다. 양쪽 Stage2 맵을 먼저 백업한다. 별도 프로세스 재로드가 저장한 액터와 그리드의 동일성을 확인한다.

- Verify02 `Saved/GameplayRepair20261111/Stage2Exit/170805-902664/report.json`: 양쪽 맵 성공, 콘텐츠 변경 없음. 맵마다 바닥 지지54점·통과 경로3줄·옆/끝 경계13회 검사.
- 그리드는25cm 간격과 기존 높이/가로폭을 유지하며 외부 바닥128셀을 추가했다. 원래 셀의 지지/비용은 월드 좌표 기준 모두 동일하다. 기존 연결12개를 출구 근처에서 추가했고 벽 거리22개만 주변에서 바뀌었다. 내부 연결을 닫거나 먼 방을 바꾸지 않았다.
- Apply01 `Saved/GameplayRepair20261111/Stage2Exit/170916-674637/report.json`: 두 맵 저장 성공, 변경 콘텐츠가 두 `.umap`뿐임을 확인. 해당 폴더의 `Before/`에 원본을 백업했다.
- Audit01 `Saved/GameplayRepair20261111/Stage2Exit/171036-398563/report.json`: 새 프로세스에서 두 맵 재로드·모든 충돌/그리드 검사 성공, 콘텐츠 해시 변경 없음. 저장된 액터와 그리드는 Apply01과 일치하고, 파일 해시도 저장 직후와 동일하다. 명령렛은 오류0으로 정상 종료했다. 기존 엔진/주석 GUID 등의 경고11개는 남았으며 새 전체 플레이 검증으로 해석하지 않는다.
- 초기 읽기 검사에서 Python의 잘못된 overlap getter를 실제 reflected property 접근으로 수정했다. Verify01은 입구 경계 검사에서 기존 문틀에 막힌 것을 새 벽 이름만 기대해 실패했다. 해당 접점은 기존 문틀도 유효한 경계로 인정하고 별도 더 안쪽 샘플은 새 벽에 막혀야 하도록 보강했다. 배치나 통과 검사를 우회하지 않았다.

검사 범위는 저장된 배치·충돌·소리/경로 격자다. 실제 완료 이벤트/추격 중 조작/전체 완주/화면에서 보이는 어두움 정도는 이번에 플레이 검증하지 않았다. C++ 변경은 없으며 새 네이티브 빌드를 실행하지 않았다. 상세 독립 리뷰는 `.superpowers/sdd/2026-11-11-stage2-exit-publish/review.md`에 보관한다.
