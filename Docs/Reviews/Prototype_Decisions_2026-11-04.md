# 작업 중 판단과 보존 사항

사용자가 승인한 로컬 프로토타입 작업 범위에서 적용한 판단이다. 최종 구현·검증 결과는 `Prototype_2026-11-04.md`, 재개 기록은 `.superpowers/sdd/2026-11-04-playable-prototype/progress.md`에 있다.

| 순서 | 판단 | 이유 | 잘못 판단했을 때의 비용 / 현재 상태 |
|---|---|---|---|
| 1 | 현재 프로젝트를 전용 브랜치에서 작업하고 시작 당시 변경 파일을 별도로 백업 | 게임플레이 에셋이 미커밋 상태이고 에디터에 로드되어 있어 HEAD만 복제하면 다른 프로젝트를 검증할 위험 | 현재 작업 폴더에 변경이 모이므로 작업별 백업·매니페스트가 필요. 원격 푸시·병합 없음 |
| 2 | SDD 작업 폴더·요구사항 추출은 PowerShell/Python으로 수행 | 당시 Git Bash 초기화가 차단됨 | 동등한 산출물이 누락되면 재개·리뷰 범위가 불명확해짐. 명시적 계획·작업별 브리프·리뷰 파일을 보존 |
| 3 | 리뷰는 HEAD만이 아닌 각 작업 시작 전후 파일을 비교 | 기존 사용자의 수정과 이번 변경을 구분 | 시작 전 상태가 없으면 변경을 잘못 귀속할 수 있음. 원본 파일·해시·시맨틱 스냅샷과 보존 한계를 기록 |
| 4 | 재시작 위치는 같은 XY·바닥에서 정착 높이 오차1cm 이내로 판정 | 실제 캡슐 충돌 스킨 때문에 정상/재시작 Z가0.25cm 차이 | 허용 범위가 작은 높이 오류를 가릴 수 있음. 원래 실패 기록과 실제 좌표를 보존하고 스폰 위치는 그대로 유지 |
| 5 | 철창의 의도된 바닥 아래 하강은 허용하고 위쪽 캐릭터·동적 장애물은 검사 | 바닥 자체를 충돌 차단하면 요청한 하강 연출이 불가능 | 잘못된 바닥 기준은 문 교차를 만들 수 있음. 실제 문 경계·바닥 오프셋과 최종 높이를 검사 |
| 6 | 에디터의 맵 덮어쓰기 잠금 때 에디터를 닫고 검증된 원본3개만 백업 위치로 옮긴 후 정식 경로에 다시 저장 | 에디터가 기존 맵 linker를 잡아 저장을 거부 | 중단 시 정식 맵 경로가 비는 위험. 모든 원본 해시를 보존했고 세 정식 맵 재생성·저장·재로드 완료 |
| 7 | 초기 Q→방울 매핑 추가 판단은 취소 | 실제 PIE 입력 컨텍스트에는 이미 SpaceBar 매핑이 있었고 옛 속성 조회가 이를 누락 | 잘못 적용하면 조작을 불필요하게 바꾸므로 입력 에셋을 수정하지 않고 SpaceBar 유지. 앞선 설명도 정정 |
| 8 | 잡기 시작 방향을 기존 들어올림 시간 동안 최단 방향으로 보간 | 실제 캡처에서90도 순간 회전을 관찰 | 각도 경계·시간 계산 오류 시 고양이가 손 반대쪽을 볼 수 있음. 경계·끝점·새 세션 회귀 검사 및 실제 렌더로 확인 |
| 9 | 전체 리뷰의 읽기 전용 코드 검사를 마지막 런타임 검사와 병행 | 에디터를 한 작업자만 사용하면서 독립 검사를 진행 | 뒤늦은 수정이 초기 리뷰를 무효화할 수 있음. 초기 리뷰로 완료 처리하지 않고 정확한 마지막 수정분과 새 증거를 별도 재리뷰 |

작업 기록과 백업은 삭제하지 않는다. 이 작업은 미커밋 변경을 포함하므로 Git 기록만으로 재개·복구할 수 없기 때문이다. 최종 종료 시 저장 상태와 에디터 프로세스 종료를 별도로 확인한다.
