## 발견하여 수정한 결함

1. **카메라 암전 위로 미니맵/저장 안내가 노출됨.** Tutorial 계단 이후 Stage1 도착 화면에서 관찰했고, 실제 PlayerCameraManager의 수동 검은 페이드로 재현했다. 기존 `ShouldHideGameplayHUD`는 false를 반환했다. 공통 표시 판정에 활성 카메라 페이드와 양수 알파를 추가했다. `StopCameraFade` 이후 남아 있는 알파 값만으로 숨김이 고착되지 않도록 활성 플래그도 검사한다.
2. **안전한 위치 복구 실패 안내가 숨겨짐.** 실패한 고양이는 안전을 위해 MOVE_None/충돌 off로 남지만, HUD 억제가 필수 재시작 안내까지 숨겼다. 해당 메시지에만 복구 정책을 부여하고, 현재 조종 Pawn과 실제 복구 실패 Pawn이 같을 때만 이동 정지 예외를 허용한다. 카메라·입력·포획·퍼즐·메뉴·전환·페이드 소유자는 계속 우선한다. 새 일반 메시지로 교체하면 예외가 초기화된다.

독립 구현/리뷰 에이전트로 조건과 Pawn 소유권을 검토했다. 메시지 검사는 실제 UMG의 `SObjectWidget::Tick`을 통해 NativeTick 경로를 실행한다. 분리 테스트 월드에서 수동으로 구동하는 Slate 검사이며, 자동 뷰포트 스케줄링 검증과 같다고 표시하지 않는다.

## 남은 범위와 관찰

- **전체 게임을 사람의 연속 손플레이로 완주한 결과가 아니다.** 튜토리얼은 정상 입력 경로를 통과했고, Stage1 바구니/포털은 분리한 국소 검사, Stage2는 첫 C 퍼즐과 포획 체크포인트까지 검사했다. Stage2 A/B 퍼즐 전체 완주와 모든 바구니의 추격 중 접근 조합은 미실행이다.
- Stage1 일부 전경 벽에서 고양이 가림이 관찰됐다. 벽 가림 처리가 전 구간에서 충분한지는 별도 카메라 품질 검사 대상으로 남긴다. 이번에 모든 카메라 가림 문제를 해결했다고 주장하지 않는다.
- 에디터 화면의 `RAY TRACING GEOMETRY - ALWAYS RESIDENT MEMORY EXCEEDS 20% OF THE BUDGET (108.009 MB / 400 MiB)` 경고가 남아 있다. 엔진 소스상 전체400MiB 초과가 아니라 상주 지오메트리가 그20%인80MiB를 넘는 진단이다. 과거 실행에도 있었고 이전 맵/에디터 로드 자원이 포함될 수 있다. OOM이나 프레임 저하는 입증하지 않았으며, 경고 숨기기/메모리 예산 증가/그래픽 일괄 저하로 덮지 않았다.

로그에 있는 엔진 시작 스모크 테스트 `Condition failed`와 기본 HUD 생성으로 추정되는 `no class specified` 경고는 Catrun 기능 검사 결과와 분리한다. HUDClass=None은 과거 에셋 기록에 근거한 유력 원인이며 이번 실행의 CDO로 확정한 것은 아니다. 정확한 시작 테스트 이름은 첫 로그의 경고 이상 출력 설정으로 기록되지 않았다. 게임 크래시로 해석하거나 해결했다고 주장하지 않는다.
