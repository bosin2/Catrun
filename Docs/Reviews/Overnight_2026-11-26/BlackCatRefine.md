## 원인과 고친 방법
1. 꼬리: 방향에서 회전을 만들 때 수직을 지나면 180도 뒤집혀 면이 꼬였다 -> 비틀림 없는 회전으로 다시 계산하고, 812면 꼬리를 저폴리 튜브로 교체.
2. 다리: 웅크리면 피부 링이 겹쳐 찌그러졌다 -> 링 순서를 강제하고, 접힌 다리는 발 바로 위의 짧은 관으로 몸통 안에 숨김.
3. 전환: 피부 보조본이 root 자식이라 혼합 중 뼈와 따로 놀았다 -> chest/pelvis/paw의 자식으로 변경.
4. 머리 뒤쪽 잔면: 같은 모양의 80면 다면체로 정리(윗부분 편차 0.00003mm). 전체 8,824 -> 6,616삼각형.
5. 동작: 긴 다리 클립을 짧은 비율로 옮기면서 발 속도·루트·이벤트는 유지. 꼬리·귀·몸 높이로 동작 구분(조심 걷기 = 낮은 꼬리와 젖힌 귀, 놀람 = 선 꼬리와 등, 도약 준비 = 깊은 웅크림).
