# Stage2 먼지·하단 빈 공간 수정

2026-11-25. 원본 프로젝트의 `Stage2`, `SoundTest_Stage2` 맵과 철창 먼지 재질에 반영했다. 이전 납품의 먼지 모양은 사용자가 거부했으며, 이 기록이 해당 재질과 두 맵의 이전 납품 해시를 대체한다.

## 수정

- 먼지의 가로·세로 주기적 사인 패턴을 제거하고 비대칭의 부드러운 구름 덩어리 다섯 개를 합성했다. Translucent 재질에서 가장자리는 완전히 투명하고, 작게 부풀어 흐른 뒤 0.78초 안에 사라진다. 중첩 시 지나치게 하얗게 뭉치지 않도록 밀도와 색 밝기를 줄였다.
- 하단의 바닥 없는 폐쇄 공간 두 곳(X1615–1735 / X1765–1885, Y2475–2595)을 기존 석재 벽과 같은 재질·높이의 구조로 채웠다. 신규 액터는 `S2_Lower_MasonryInfill_01`, `02`이다. 기존 벽으로 이미 사방이 막혀 있는 공간이며, 시각 보완용 구조에는 새 충돌이나 SoundWall 태그를 추가하지 않았다.
- Stage2의 기존 액터 948개와 SoundTest_Stage2의 605개 요약과 저장된 소리 전파 그리드가 보존됐다. 철창 Blueprint·카메라·갑옷·촛불·소스·DLL은 이번 작업에서 수정하지 않았다.

## 검증과 범위

- 별도 스냅샷의 DX12 PIE에서 A/B/C 실제 철창 완료 이벤트와 효과 정리·입력 복귀 3/3 성공. C의 먼지 중간 시점도 추가 촬영하여 반복 무늬·사각 경계·불투명 덩어리가 보이지 않는지 확인했다.
- 하단은 원래 게임 카메라로 전후 촬영했다. 앞뒤 비교의 이전 상태는 PIE에서 새 구조물 둘만 일시 숨긴 것으로, 원래 지오메트리는 유지했다. 같은 위치에서 주변 경로로 2.04초간 129.7cm 실제 이동을 확인했고, 포획 없이 입력·가시성을 복원했다.
- PIE 종료와 저장 맵 해시 불변을 확인했다. 원본 패키지의 작업 시작 해시를 다시 검사하고 백업한 뒤 검증한 3개 파일만 교체했으며, 반영 후 해시는 테스트한 스냅샷과 일치한다.
- 전체 스테이지 수동 플레이 완료나 사용자 미술 승인을 주장하지 않는다. 근거는 `Saved/Stage2DustAndMasonryCorrection_20261125`의 Evidence·Screenshots·publication.json에 있다. 초기 patch 보고서의 runtime_verified=false와 shader 제안 주석은 적용 직후의 과거 상태이며, 이후 수행한 DX12 실행 보고서가 현재 검증 상태다.

다른 채팅의 에디터나 Blender를 조작하지 않았다. Git 커밋·푸시는 하지 않았다.
