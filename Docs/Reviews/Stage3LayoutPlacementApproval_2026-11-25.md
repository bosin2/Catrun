대상 본파일은 `Content/Maps/Stage3.umap`이다. 에셋 조사, 도면 대조, 통행 검사를 병렬 담당자가 나누어 수행했고, Unreal 실행은 한 담당자가 순차 조율했다. 이 문서는 사용자 요청인 “수정방안 설명 후 승인받고 진행”을 위한 결과다.

## 권장안

제단실 외곽 **10×6m와 나머지 방 크기는 유지**한다. 현재 검사에서 맵 전체를 비례 확대해야 할 근거는 발견하지 못했다. 현재 작은 중앙 ㄴ벽 하나를 도면처럼 **위쪽에서 내려오는 벽 2개와 아래 ㄴ/ㄱ벽 2개**로 바꾸고, 출입구 3곳을 둔다.

![현재와 제안 비교](../../Saved/Stage3ApprovalAudit20261125/altar_proposal.png)

이 안은 기존 텍스트의 “1.5×1.5m 내부 구조물”을 **아래 ㄴ/ㄱ벽 각각의 외곽 크기**로 해석한다. 원문에서 확정된 해석이 아니므로 그림과 함께 사용자의 승인이 필요하다. 기존 중앙의 작은 ㄴ벽을 별도로 남기는 안은 아니다.

| 변경 | 구체적인 제안 | 이유 |
|---|---|---|
| 제단실 내부 벽 | 두께 30cm, 높이 300cm, 총 6개 직선 구간 | 도면의 분절된 좌우 벽 형태 복원 |
| 좌우 출입구 | 각각 순수 벽체 간격 125cm | 고양이 지름 40cm·갑옷 지름 70cm 통행 여유 |
| 아래 중앙 출입구 | 벽체 간격 230cm | 중앙 장치 접근과 순찰 경로 확보 |
| 중앙 당김 장치 E3 | 도면 위쪽으로 50cm 이동 | 새 벽을 그대로 추가하면 장치 앞 갑옷 여유가 부족함 |
| E3 이동 범위 | 로컬 하우징·고리·핀·풀리·체인·표시물 함께 이동; 성문 쪽 잠금쇠는 고정 | 기존 장치 연결·상호작용 유지 |
| 제단 갑옷 | 시작점과 순찰점 변경 | 기존 시작점이 새 아래 벽과 겹침 |
| 오른쪽 중량추 P2 | 위치와 도킹 축 유지 | 현재 밀기 방향 보존. 왼쪽 60cm는 고양이, 오른쪽 100cm는 고양이·갑옷 통행 |

좌표는 사용자 도면의 오른쪽 +X, 위쪽 +Y, 단위 cm이다. 실제 저장 월드는 `(X, -Y, Z)`다.

|---|---:|---:|
| 왼쪽 상단 | 110~140 | 2375~2550 |
| 오른쪽 상단 | 610~640 | 2375~2550 |

| 오른쪽 아래 가로 | 490~640 | 2100~2130 |

E3 중심은 `(375,2240)`에서 `(375,2290)`으로 이동한다. 갑옷 시작점은 `(550,2190)`, 순찰은 `(550,2190) → (550,2380) → (200,2380) → (200,2190)`이다.

단순히 벽만 추가하는 안은 제외했다. 기존 갑옷 시작점은 새 벽과 25cm 겹치며, 장치를 그대로 두면 아래 벽과 하우징 사이가 80cm라 지름 70cm 갑옷의 양쪽 여유가 5cm뿐이다. 권장안은 장치와 경로를 함께 옮겨 해결한다.

## 에셋 조사 및 고딕 군사시설 배치안

실제 Unreal Asset Registry와 디스크 패키지를 대조했다. 환경 패키지는 **415/415개**이고, 정식 납품 FBX **99/99개**에 대응하는 임포트 패키지가 있다. 조사한 납품 범위에서 미임포트는 0개다. 기각된 동상 원형과 Review용 특수 바닥은 정식 신규 납품으로 세지 않았다.

환경 메시 114종 중 보이는 배치 83종, 전부 숨겨진 채 보존된 배치 12종, 직접 미배치 19종이다. 미배치 중 `DockShortChain`은 의존성이 있으므로 미사용으로 세지 않는다. 나머지 **18종은 현재 직접 배치·의존성이 없는 후보**다. 예비 모듈과 대체품까지 일괄 추가하거나 삭제하지 않는다. 별도 Stage3 바구니 SM/SK 2종도 미배치이지만 은신 게임플레이 변경이므로 이번 분위기 배치안에서 제외한다.

## 실제 통행 검사

현재 저장 맵: **26/26개 검사 통과**. 제단 갑옷 기존 native 순찰 2회, 고양이 10개 경로의 물리 이동 왕복을 확인했다.

제안 B1은 별도의 숨김 Unreal 프로세스에서 벽·E3·순찰점만 메모리상 바꿔 검사했다. **51/51개 검사 통과**:

- 제단 갑옷의 기존 게임 코드에 의한 순찰 2회. 순서 `0→1→2→3→0→1→2→3→0`, 약 33.71게임초.
- P2 오른쪽 100cm 통로에서 갑옷 실제 길찾기 왕복 2회. 측정 중심 X 861.98~862.50cm로 캡슐이 통로 안에 유지됨.
- 고양이 16개 경로·42개 이동 구간의 실제 입력 기반 왕복 완료. 새 좌우/중앙 개구부, P2 양옆, 캣홀, 주요 연결부 포함.
- 새 좌우 125cm·중앙 230cm 개구부에서 갑옷 실제 캡슐에 추가 5cm 여유를 둔 충돌 검사 통과.
- P2 왼쪽 60cm는 고양이 실제 통과, 갑옷은 충돌 검사에서 차단. 이쪽을 갑옷 경로로 사용하지 않음.

이 검사는 장애물 통행을 분리해서 확인하는 시험이다. 다른 NPC를 비활성화했고 각 독립 경로 시작에 한 번 안전한 위치로 옮겼다. 이동 도중에는 실제 CharacterMovement와 갑옷 native 길찾기를 사용했다. 순찰 도착 판정에는 게임의 경로 허용오차가 적용된다. 전체 잠입 난이도나 전 스테이지 플레이 완료를 증명하는 검사는 아니다.

새 세 개 개구부의 추가 native 시험도 **27/27개 검사 통과**했다. 갑옷이 좌125cm·우125cm·아래중앙230cm를 각각 2왕복했고, 각 이동이 해당 벽의 중심면을 실제로 가로질렀는지 및 캡슐 전체가 개구부 안에 있었는지 확인했다. 외부 우회는 통과로 인정하지 않았다. 안전한 경로 시작 배치와 초기 길찾기 안정화 이후에는 native 이동만 사용했다.
