# 튜토리얼 복구와 촛불·갑옷 수정

사용자 요청: 기존 튜토리얼 연출·조작 안내 복원, 추가 설명과 페이드 철회. 촛불에 발각되면 기준 거리 안의 갑옷이 벽 너머에서도 표식에 반응하고 경로의 문을 열어야 한다.

## 변경

- `BP_TutorialIntro`를 수정 전 백업으로 복원했다. 현재 파일과 Git HEAD의 blob 해시는 `d004caa5c8daec1261d876866345929174314992`로 동일하다. 기존 `WBP_Tutorial_KeyHint` 생성과 표시를 유지한다.
- `SoundTest_Tutorial`을 원래 배치로 복원했다. 추가 안내 구역 7개, 추가 방울 금지 구역, 복도 문 시작 열림을 철회했다. 이후 사용자 확정 규칙에 필요한 `SoundGridManager.bMarkAttractsArmors`만 활성화했다.
- 튜토리얼에서 새 C++ PlayHUD를 생성하지 않는다. 공통 레벨 이동에 추가했던 페이드를 제거했다. 기존 인트로·계단 BP 자체의 페이드는 유지한다.
- `setup_playability.py`는 Stage2만 다루도록 변경하여 다시 실행해도 튜토리얼을 덮어쓰지 않는다.
- 표식 호출 거리를 `DA_SoundSettings.MarkCallRadius`로 통합했다. 초기값 1,500cm, 수평 직선 거리 기준이며 벽·닫힌 문은 호출을 막지 않는다. 기존 가장 가까운 갑옷 1기 선택 규칙을 유지한다. 실제 이동은 경로 탐색과 문 열기를 사용한다.
- 촛불이 추적 상태를 유지하는 동안 표식이 지워지면 재발각되어도 표식이 다시 붙지 않던 오류를 수정했다. 바구니 진입 중인 고양이에게 표식을 다시 붙이지 않도록 은신 진입 판정도 사용한다.
- 갑옷이 문 여는 애니메이션 중 고양이를 잡으면 문 제어·몸 이동·좌우 반전 정리가 생략되던 오류를 수정했다. 포획이 승인된 경우 현재 애니메이션 이동을 실제 위치에 반영하고 문이 남은 회전을 끝내도록 해제한다.

## 검증

- 최신 `CatrunEditor Win64 Development` 빌드 성공: `Saved/Logs/Restoration-Build-Final.log`.
- Catrun 자동 테스트 15개 모두 통과: `Saved/Restoration/TestsFinal/index.json`. 거리 제한·벽 너머 호출·촛불 재표식 회귀 테스트 2개를 포함한다. 수정 전 해당 테스트 실패도 기록했다(`TestsRed`).
- 렌더링된 PIE에서 기존 인트로 자연 종료, 기존 조작 안내 표시, 추가 HUD 없음, 문 닫힘, 실제 계단 overlap, 계단 시네마틱 재생, Stage1 도착 후 입력 복원을 확인했다: `Saved/Restoration/tutorial-pie.json`.
- 렌더링된 PIE에서 촛불에 의한 실제 표식과 갑옷 호출 후, 문 여는 도중 포획 전환을 확인했다. 갑옷 몸 위치가 약 76cm 반영되고, 문이 약 -90도까지 열리며, 메시 스케일이 원래 `(1,1,1)`로 복원됐다. 경로 밖 복도 문은 닫힌 상태를 유지했다: `Saved/Restoration/mark-pie.json`.
- 별도의 렌더링된 PIE에서 발각된 고양이를 방 안쪽 시작 위치로 이동시켜, 갑옷이 문을 완전히 열고 실제로 방 안까지 진입하는 것도 확인했다. 문 회전 -90도, 갑옷 Y 좌표 약 178cm(문 위치 약 465cm), 무관한 복도 문 닫힘: `Saved/Restoration/mark-entry-pie.json`.
- Stage2 회귀 검사도 통과했다. A/B/C의 실제 F 처리 진입점으로 각 방 동상만 복원하고, 메뉴 확인 후 재시작하여 시작 위치·입력을 복원했다. 이 검사는 렌더링 없는 PIE이며 `Saved/Flow/Playability/pie.json`, `Saved/Logs/Restoration-Stage2-Regression.log`에 기록했다.

PIE 검사는 재현 위치로 순간이동한 뒤 실제 게임 로직을 관찰한다. 시네마틱 완료 함수나 표식·문 열기 함수를 직접 호출해 성공으로 처리하지 않는다. 수동 전체 완주와 패키지 실행 검증은 별도다. 변경은 로컬 작업이며 커밋·푸시는 하지 않았다.
