# Stage2 두 번째 방 배치 수정

사용자가 첨부한 노란 경계·초록 순찰선 이미지의 두 번째 방, 동상 A 퍼즐을 수정했다. 기존 방은 이미750×500cm로 축소되어 있어 건축 형상은 유지했다. 북쪽 출입구·캣홀도 유지했다.

| 대상 | 이전 XY(cm) | 수정 XY(cm) |
|---|---|---|
| 동상 A | 2075,2775 | 2360,2825 |
| 발판 A·프레임 | 2075,2555 | 2110,2825 |
| 갑옷 02 | 2187.5,2712.5 | 2312.5,2687.5 |
| 순찰 1 | 2187.5,2537.5 | 2087.5,2687.5 |
| 순찰 2 | 2187.5,2887.5 | 2562.5,2687.5 |
| 바구니·본체·천 | 2390,2820 | 2530,2800 |

동상은 하단 중앙, 발판은 그 왼쪽에 놓아 서쪽으로 밀어 안착하도록 했다. A의 SocketAxis를Y→X로 변경하고 기존 Gate02 연결은 유지했다. 바구니는 새 동상 자리와 겹치므로 같은 방의 오른쪽으로 이동했다. 각 액터의 높이·크기·재질은 유지했다. 갑옷은 위쪽 두 순찰점을 좌우 왕복한다. 속도·감지 반경·AI·동상 밀기 규칙은 변경하지 않았다.

## 반영 및 검사

- `/Game/Maps/Stage2`, `/Game/Maps/SoundTest_Stage2` 두 저장 맵에 반영했다.
- 두 맵에서 대상9개 액터 위치를 검사하고 각각599개/595개 다른 액터의 형상·위치·메시·재질·태그 보존을 비교했다. 천구의·마법회랑 조명·장식과 B/C 퍼즐 연결을 보존했다.
- 사운드 그리드를 다시 계산했다. Walkable·격자 규격은 불변이고, 바구니 주변 Room2 내83개 WallDistance 값만 바뀌었다. 건축 바닥·벽이 변하지 않아 미니맵 바닥 텍스처는 유지했다.
- 실제 고양이 캡슐과 ExitDistance82cm로 바구니 동서남북 탈출선의 충돌·도착 바닥 지지를 검사했다. 네 방향 모두 통과했다. 이는 캡슐 경로 검사이며 바구니 애니메이션 전체 플레이 검사는 아니다.
- 실제 PIE 무유인 비교 경로에서는 갑옷02가 발판 안착 전에 고양이를 잡았다.
- SoundTest_Stage2의 실제 방울·이동·기본 AI 검사에서 북쪽 복도(2535,2325)의 방울1회로 갑옷을 방 밖으로 유인하고, 캣홀06으로 우회해 A를 안착시켰다. 안착 겹침1.0, 동상·발판 중심(2110,2825) 일치, Gate02 상단Z=-34cm와 입력 복귀를 확인했다. 무유인 비교 검사는Stage2에서 수행했다. 위치를 한 번 바닥 지지 검사 후 배치하는 시작 fixture 외에 순간이동·무적·AI중지·속도 변경을 사용하지 않았다.
- 비교 검사는 선택한 접근 경로의 결과다. 모든 가능한 무유인 공략이 불가능하다는 수학적 증명이나 전체 스테이지 완주 검사는 아니다.
- 검사 중 저장 맵 해시는 불변이었다. 원본 두 맵이 작업 시작 기준과 동일한지 확인한 뒤 검증 사본과 해시가 일치하도록 반영했다. 다른 채팅의 편집 세션은 변경하지 않았다.
