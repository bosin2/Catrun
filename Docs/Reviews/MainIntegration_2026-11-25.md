# main 통합 게시 — 2026-11-25

사용자의 “GitHub main에 푸시, 분리된 작업물도 전부 포함” 요청으로 현재 본 프로젝트 변경과 Git 워크트리의 미반영 결과물을 통합했다. 후속 요청에 따라 **카메라의 X축 반대편 전환은 Stage3에만** 적용했다.

## 포함한 작업

- Stage3 고딕 재질·조명·소품·러그·퍼즐 표현, 원도면 배치 및 실제 화면 좌우 방향 수정.
- Stage3 배치 카메라 yaw -45→-135. 실제 플레이 yaw -135 및 입구/성문 홀 캡처 확인. Stage1/2 맵과 공유 카메라 BP는 이 카메라 수정 전후 해시가 동일하고, 다른 액터 1,451개 변환도 유지됐다.
- 본 프로젝트의 바구니 상호작용·튜토리얼 캣홀·완료된 Stage2 천구의/마법 복도 에셋·오디오 도구와 설정 변경.
- `5825` 워크트리의 고딕 HUD·상태 표시·단순 반투명 미니맵 마커와 검사 코드·문서 10개.
- `3158` 워크트리의 Blender 제작 지침·프롬프트·기존 에셋 참고자료 8개.
- `110f` 워크트리의 고양이 리그 연구 원본·스크립트·검사·프리뷰 1,327개. **사용자가 자연스럽지 않다고 지적한 실험본이 포함되며 최종 승인된 게임 리그가 아니다.** SourceArt로 보존하며 게임의 고양이 메시·리그를 이 파일로 교체하지 않았다.
- `7c1b`의 기획 문서 5개는 이미 본 프로젝트에 반영된 상태를 확인했고, 최신 정정을 보존하며 오래된 Stage3 미구현 문장만 정리했다.
- 게시 준비 중 납품된 승강기 고양이 애니메이션 9종과 점프→당김→착지 연속 마스터, FBX 10개, Blender 원본·프리뷰·접촉 데이터·DELIVERY 문서를 포함한다. 검토용 납품이며 C05 꼬리 부풀기는 제외됐다. 사용자 아트 승인과 Unreal 임포트/연결은 별도다.

Git 워크트리 11개(본 프로젝트 포함)를 확인했다. 분리된 HEAD에 main 미포함 커밋은 없었으며 변경 파일을 내용 기준으로 통합했다. 나머지 워크트리에는 미반영 파일이 없었다. 로컬 에디터 캐시·빌드 산출물·Saved 로그·`.superpowers` 에이전트 작업 캐시는 게시 대상에서 제외했다. 새 SourceArt 대용량 바이너리는 Git LFS로 저장하며 기존 Git 이력은 재작성하지 않았다.

## 검증 범위

- Stage3 좌우 방향 수정 후 네이티브/이동 회귀 188건 및 독립 지형/보존 검사 13건 통과. 이후 사용자 요청으로 바꾼 카메라는 별도의 저장 맵 플레이 검사로 yaw -135와 두 지점을 확인했다. 188건 전체를 새 카메라에서 재실행했다고 주장하지 않는다.
- HUD 작업 트리 보고서에는 최종 네이티브 빌드, 미니맵 자동 검사 7개, Stage1 라이브 검사 1개 통과가 기록되어 있다.

- Stage2 방2의 새 배치·유인 동선은 별도 격리 작업 공간에서 검증이 진행 중이며, 미납품 중간 맵으로 현재 원본 Stage2를 덮어쓰지 않았다. 완료된 천구의/복도 수정은 포함되어 있다.
