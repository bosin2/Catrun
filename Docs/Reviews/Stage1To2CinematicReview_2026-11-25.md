전체 출발 길이는 **339프레임 / 11.3초**다. 탐색 카메라는 낮은 앞쪽 3/4에서 앞발과 양쪽 귀를 담고 정적을 유지한다. 갸웃 종료 때 낮은 뒤쪽 3/4로 전환하여 전신과 포탈 입구를 담는다. 마지막 뒷발 지지 f279까지 같은 정지 샷이며 이륙 후에 따라간다.

실제 재생에서 발견하고 수정한 사항:

- 기본 애니메이션 압축이 작은 접지 키를 지워 앞발이 약 1.48cm 움직이고 두 번째 흔들기가 약해졌다. 새 세 클립에만 정밀 압축을 적용하여 앞발 변위가 0.001cm 미만으로 줄었고 네 개의 좌우 극점이 복원되었다.
- 탐색 중 귀 끝과 높은 도약 중 머리가 잘리던 구도를 조정했다. 포탈 기둥이 화면 가장자리를 가리던 카메라 위치도 보정했다.
- 새 압축 자세를 그대로 받는 0.3초 연결 동작을 사용해 기존 점프의 준비 구간을 반복하지 않는다. 실제 압축된 애니메이션 기준 기존 점프 연결점 최대 본 위치 오차 0.00841cm, 회전 오차 0.0431°다.
- 앞발 접촉 위치에 작은 청색 일렁임을 한 번만 표시한다. 충돌과 게임플레이 소리 전파에는 관여하지 않는다.
- 최종 재촬영 전 글로벌 `Shot` 요청이 접촉 순간 한 프레임을 에디터 뷰포트에서 가져오는 문제를 발견했다. `CatrunAuthoringLibrary.CaptureGameViewport`가 해당 PIE 플레이어의 뷰포트를 직접 읽도록 보완하고 다시 빌드했다. 실패한 프레임을 편집으로 대체하지 않는다.

관련 재현 스크립트는 `Scripts/GameplayRepair/PortalEntry20261125/`와 `Scripts/GameplayRepair/CinematicReview20261125/`에 있다. 기존 파일 보호 해시 검사에서 변경된 기존 콘텐츠는 출발/도착 시퀀스 두 개뿐이며, 나머지 보호 대상 37개는 동일하다.

남는 한계: 깊게 접은 다리의 몸통 접합부에는 원래 메시/스킨의 작은 주름이 남는다. 원본 외형과 가중치를 보존한 애니메이션 작업이며, 제작자가 기록한 이 표면 한계나 사용자 미술 승인을 수치 검사 통과로 대신하지 않는다.
