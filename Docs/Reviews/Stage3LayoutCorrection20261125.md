# Stage3 참고도 외곽 및 연결부 수정 — 2026-11-25

사용자가 다시 지정한 원본 평면도에 맞춰 `/Game/Maps/Stage3`의 실제 바닥·벽과 연결된 소품/퍼즐 위치를 수정했다. 이전 버전은 개별 방 치수만 맞고 전시방의 왼쪽 오프셋, 제단실 왼쪽 돌출부, 상단 복도와 제단실 사이 분리 공간이 참고도와 달랐다.

## 반영한 수정

- 전시방 전체를 왼쪽으로 150cm 이동하고, 하단 복도에 연결되는 짧은 가로 구간을 복구했다. 연결부 상단은 Y=1600으로 평평하게 정리했다.
- 제단실 왼쪽 연결부를 꺾인 형태로 수정하고, 상단 복도와 제단실 사이에 50cm 분리 공간을 만들었다. 이전의 직접 연결은 벽으로 막았다.
- 상단 복도와 성문 홀을 X/Y 각각 -50cm 이동했다. D2 중심 Y=2300부터 성문 홀 입구 Y=2900까지 600cm다.
- 로비 하단 칸막이 오른쪽 150cm 구간을 열고, 해당 통로를 막던 중복 벤치와 작업대 2개를 제거했다. 신규 고딕 벤치와 창고 작업대는 유지했다.
- 기존 액터 147개의 위치를 참조와 함께 옮겼다. 퍼즐 연결, 목표 장치, 문과 성문 액터의 식별자를 유지하고 Dock1의 저장된 월드 좌표도 보정했다.
- SoundGrid와 Stage3 미니맵을 새 바닥/벽에서 갱신했다. 기존 조명·Stage3 재질·대형 러그·상호작용 장치의 불투명 처리는 유지했다.

## 치수와 해석 범위

`Scripts/Stage3/layout.py`의 11개 공간은 사용자가 지정한 외곽 가로×세로 치수다. 추가 연결 공간 `ExhibitionBridge`와 `MainEntry`는 통행 연결부이며 별도의 방으로 계산하지 않는다.

제단실 왼쪽 추가 구간의 외곽은 550×150cm이지만, 현재 배치에서는 본체와 200×150cm 겹친다. 따라서 이를 본체에 더해진 순수 추가 면적 8.25m²라고 주장하지 않는다. 이미지의 상대 배치와 명시된 치수를 좌표화한 해석이며, 원본 이미지의 모든 픽셀 비율을 복제한 결과는 아니다. 제단실 내부 구조물의 기준 영역은 명시된 150×150cm를 유지했다.
