# Stage2 마법회랑 조명·공간 장식 반영

기존 B안 천구의와 공간을 유지하며, 천구의 전용 조명과 은은한 보라빛 회랑 장식을 추가했다. 주황색으로 공간을 바꾸지 않고 기존 푸른 조명을 라일락·보라 쪽으로 소폭 조정했다.

## 반영 위치

- 원본 프로젝트 레벨: `/Game/Maps/Stage2`, `/Game/Maps/SoundTest_Stage2`
- 새 에셋: `/Game/Environment/Stage2/MagicCorridor_20261125` (검색어 `MagicCorridor`)
- 아웃라이너 폴더: `Stage2/MagicCorridor/Decor`, `Stage2/MagicCorridor/Lighting`
- 근거 자료·Blender 원본·FBX: `Saved/Stage2MagicCorridor_20261125`

## 변경 내용

| 항목 | 배치 수 | 내용 |
|---|---:|---|
| 천체 명판 | 6 | 보라색 석판, 황동 테두리·초승달, 작은 발광 별 |
| 수정 차임 | 4 | 세 갈래 수정, 금속 고리와 연결부 |
| 차임 브래킷 | 4 | 벽 지지대와 차임 연결점 일치 |
| 천체 바닥 문양 | 1 | 외경330cm·내경180cm, 천구의 받침을 둘러싸는 황동 선·별 |
| 길잡이 문양 | 5 | 지름55cm, 문턱과 이동 공간의 작은 장식 |
| 전용 조명 | 3 | 천구의 키·필·림, 밝은 라일락 계열 |

총 5종 메시·3종 머티리얼, 맵당 장식20개와 신규 조명3개. 기존 건축 조명30개의 색을 조정했고, `Light_Stage2_*` 광량은180→195lm으로 소폭 높였다. 천구의 전용 조명은 키2200lm·필350lm·림1000lm이다. 기존 DirectionalLight 강도·색온도와 게임플레이 촛불·감지 규칙은 유지했다. 신규 조명 중 키만 그림자를 생성한다.

새 장식은 황동·보라색 석재·라일락 발광의 공통 재질을 사용한다. 황동과 석재는 미세한 거칠기 변화를 가진다. 바닥 선이 실제 카메라에서 가늘게 끊겨 보여 외곽1.8cm·안쪽1.6cm·호1.4cm·연결선0.8cm로 보강했다. 독립 Blender 프로세스에서 제작·렌더·FBX 왕복검사를 수행했다.

## 검증

- 새 프로세스에서 두 저장 맵을 다시 로드해 에셋5종, 재질 슬롯, 장식20개, 조명3개, 벽 장식 방향과 높이·브래킷 연결점을 검사했다.
- 기존 Stage2 585개 / SoundTest_Stage2 581개 액터의 형상·배치·태그·메시·재질 참조를 보존했다. 기존 콘텐츠는 대상 두 맵 외 해시 불변을 검사했다.
- 기존 사운드 그리드·퍼즐 링크·충돌 검사 결과를 보존했다. 모든 새 장식은 NoCollision이며 내비게이션에 영향을 주지 않고 SoundWall 태그가 없다.
- 두 맵 모두 실제 PIE에서 천구의 자연 회전, 96초 애니메이션 루프 경계, 실제 고양이 이동에 의한 받침대 차단, 중앙 통과12개·우회4개 캡슐 검사, 게임 카메라 캡처를 수행했다. 구체적인 측정값은 RuntimeQA 각 맵의 report.json에 있다.
- 테스트와 캡처 후 저장 맵 해시 불변을 확인했다. 검증된 새 패키지8개와 맵2개만 원본으로 복사했고, 복사 직전 원본 맵의 기준 해시를 재확인했다. 원본 파일과 검증 사본의 해시 일치도 확인했다.

기존 scene_tests의 갑옷 동쪽·남쪽 경로에는 Candle_02 충돌이 그대로 기록되어 있다. 이번 검사는 기존 결과 보존을 확인하며, 전체 경로가 모두 비어 있다는 뜻은 아니다. 전체 스테이지 수동 완주와 정량 FPS 측정은 수행하지 않았다. 에디터 전체샷은 벽/천장 가림 일부를 제외한 검사용 캡처이고, 실제 게임 화면은 별도 PIE 캡처다. 다른 채팅의 에디터·Blender 세션을 조작하지 않았다. Git 커밋·푸시는 수행하지 않았다.
